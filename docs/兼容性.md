# 通达信（TDX）公式兼容性一览

粘进来的通达信 / 同花顺匹配公式分三档：**支持的**（粘进来就能跑）、**忽略的**
（不影响匹配，界面写明"已忽略"）、**不支持的**（给中文原因 + 替代写法，不会崩、也不会静默算错）。

本页的数字与清单以当前代码为准：`src/laoa_trader/strategy/formula.py` 里的
`FUNCTIONS`（**80 个函数**）、`EXTRA_FIELDS`（**16 个扩展字段**）、`UNSUPPORTED_FUNCTIONS`（2 个）
与实时快照字段；`tests/test_tdx_compat.py` 与 `tests/test_formula.py`（函数个数与本文的一致性）的用例守着每一档，谁改坏了哪一条，测试立刻红。

## 一、支持（直接可用）

### 语法

| 通达信写法 | 说明 |
|---|---|
| `;` 语句分隔 | 一行一句、或整条写在一行（`A:=1; B:=2; A>B;`）都行；引号内的 `;` 不受影响 |
| `:` 输出线 | `MA5:MA(C,5)` 照收（匹配用不到画线，等同定义变量） |
| `:=` 中间变量 | 与通达信一致（只算不输出） |
| 注释 `{}`、`//`、`#` | 三种都认；`#WEEK` 这类周期词例外，见第四节 |
| `<>` | "不等于"（内部按 `!=` 处理） |
| 全角标点 | `（），：；＞＜＝＋－＊／！％．“”‘’` 全部当半角处理 |
| `AND / OR / NOT`、`&& / \|\| / !` | 大小写都认 |
| 字符串 | 单双引号都认，中文引号 `“ ”` 也认（`INDUSTRY=“半导体”` 能过） |

### 字段

**基础字段 9 个**（共 17 种写法）：`C / OPEN / HIGH / LOW / VOL / AMOUNT / PRE_CLOSE / DATE / INDUSTRY`，
别名 `CLOSE / O / H / L / V / VOLUME / AMO / PRE`。

**扩展字段 19 个**（`EXTRA_FIELDS`，中文名，**不设英文别名**）：

| 字段 | 含义与单位 | 数据来源 |
|---|---|---|
| `流通市值` | 亿元 | 实时快照 |
| `换手率` | % | 实时快照 |
| `现价` `现涨幅` `现量比` `现换手` | 现价（元）/ 当日涨幅（%）/ 量比（倍）/ 换手率（%） | 实时快照，**盘中四个字段** |
| `主力净额` | **亿元**（最近一个交易日的主力资金净额；正数 = 净流入） | **本地库**（东方财富公开接口采的资金流，**只对自选标的采**） |
| `主力净占比` | **百分数**（18.02 = +18.02%） | 同上 |
| `近5日主力净额` | **亿元**（最近 5 个交易日的主力净额之和；入库不足 5 天时就是能取到的那些天之和） | 同上 |
| `竞价匹配额` | **万元**（9:15–9:25 集合竞价**撮合出来的金额**；接口给的是元，进引擎前已 ÷1e4） | 同花顺集合竞价接口（**要 Key**，只有 **9:15–9:30** 取得到） |
| `竞价匹配量` | **手**（竞价撮合的量） | 同上 |
| `竞价未匹配量` | **手**，**带符号**：`>0` 买盘剩余（买强）、`<0` 卖盘剩余（卖强）；接口用 **-1** 表示"未提供"，引擎把它当**缺值** | 同上 |
| `热门行业` | 最近 3 个交易日上榜次数（0~3） | 本地库（离线算） |
| `ST` `科创` `北交所` `沪市` `深市` `创业板` | 0/1 标记 | 代码/名称推出（不用联网） |

⚠️ **单位**（这里最容易错，差 1e8 倍）：`主力净额` / `近5日主力净额` 是**亿元** ——
库里存的是**元**（接口口径），进引擎之前已经 ÷1e8，所以写 `主力净额>1` 就是"主力净买入过亿"。
`主力净占比` 是**百分数**（`18.02` 表示 +18.02%，不是 0.1802）。

⚠️ **竞价那三个字段的单位**（差 1e4 倍就静默错，所以写死在这里）：
`竞价匹配额` 是**万元** —— 接口给的是**元**，进引擎之前已经 ÷1e4，所以写 `竞价匹配额>=1000`
就是"竞价撮合了 1000 万元以上"（**别**按元去写 10000000）；`竞价匹配量` / `竞价未匹配量`
是**手**（接口原值）。它们**只是竞价那一段**，与全天成交额 `AMOUNT`、昨收量都**不是一回事**。

排除写法可以直接写成一串：`ST=0 AND 科创=0 AND 北交所=0`。

### 函数（80 个）

- 均线 / 平滑（6）：`MA EMA EXPMA SMA DMA WMA`
- 引用与窗口（10）：`REF HHV LLV HHVBARS LLVBARS SUM COUNT SUMBARS BARSCOUNT BARSSINCE`
- 条件与计数（13）：`CROSS BARSLAST EXIST EVERY BETWEEN RANGE FILTER UPNDAY DOWNNDAY NDAY LONGCROSS VALUEWHEN LAST`
- 统计与回归（6）：`STD STDP VAR AVEDEV SLOPE FORCAST`
- 指标（14）：`DIF DEA MACD RSI RSV K D J BOLL UB LB OBV WR CCI`
- 趋势 / 波动 / 资金（5）：`ATR PDI MDI ADX MFI`（都是 Wilder 口径，窗口默认 14）
- 数学（16）：`ABS MAX MIN IF IFF POW SQRT LOG LN EXP MOD INTPART ROUND CEILING FLOOR SIGN`
- 涨跌停价（2）：`ZTPRICE DTPRICE`（打板 / 回踩类公式常用）
- 代码 / 名称判定（2）：`CODELIKE('300')`、`NAMEINCLUDE('ST')` —— 逐票恒定的 0/1，可直接进 `NOT(...)` / `OR`
- 通达信口径映射（3）：`FINANCE(...)` / `DYNAINFO(...)` / `INBLOCK(...)`，见第四节
- 本项目特有（3，数据来自本地库）：`涨停天数 连板 量比`

### 几个容易算错的点（实现里都按通达信口径）

- `SMA(X,N,M)` 是**加权递推** `Y=(M*X+(N-M)*Y_prev)/N`，**不是** N 日简单平均；KDJ 里 `K:=SMA(RSV,3,1)` 就是这个语义。
- `ATR` / `PDI` / `MDI` / `ADX` 用的是 **Wilder 平滑**（`Y=(Y_prev×(N-1)+X)/N`，即 α = 1/N，首值取前 N 根的简单平均），**不是** `EMA` 的 α = 2/(N+1) —— 拿 `EMA` 顶替的话同一段行情算出来的数值就不一样了。
- `ADX(N)` 要的历史是 ±DI 的**两倍**：DX 先用掉 N 根、ADX 再对 DX 平滑 N 期，所以 `ADX(14)` 的曲线要到第 28 根 K 线才有第一个值（`ATR/PDI/MDI/MFI` 是第 N+1 根）。历史不够时一律是**缺值**，条件不成立。
- `MFI(N)` 是"带量的 RSI"：典型价 `(H+L+C)/3` 与上一根比，涨记正向、跌记负向、**持平那一根两边都不进**；资金流用**成交量**（不是成交额）。
- `HHVBARS(X,N)` 返回"最高值距今多少根"（0 = 本根）。
- `BETWEEN(X,A,B)` 不要求 A<B，谁大谁小都认。
- 小技巧：排除板块不必写一长串 `NOT(CODELIKE('300') OR CODELIKE('688') …)`，写成 `创业板=0 AND 科创=0 AND 北交所=0` 更短也更直白（`沪市` 含科创、`深市` 含创业板，两个标记是独立的）。
- `ZTPRICE(昨收, 比例)` / `DTPRICE(昨收, 比例)`：第二个参数是**比例小数**（`0.1` = 10%，不是 `10`），省略时按 10%；取整按**这只票所属板块**（北交所涨停向下截断、跌停向上取整，其余四舍五入到分）。
- 窗口不足时结果是**缺值**（不产生信号），不会拿更短的窗口凑一个数。

## 二、忽略（不影响匹配，界面会写明）

| 通达信写法 | 处理 | 界面会怎么说 |
|---|---|---|
| 画图语句（**25 个**：`DRAWICON / DRAWTEXT / DRAWKLINE / STICKLINE / POLYLINE / DRAWBAND / FILLRGN / VERTLINE / HORLINE / PARTLINE / RGB …`） | **整句跳过** | `ℹ️ 第 N 行的画图语句 DRAWICON(…) 已忽略（画图对筛选没有影响）` |
| 样式修饰（**39 个**：`,COLORRED / ,LINETHICK2 / ,NODRAW / ,CIRCLEDOT / ,SHIFT3 …`） | 吃掉，不影响结果 | `ℹ️ 已忽略样式修饰：COLORRED、LINETHICK2` |

为什么忽略而不是报错：通达信匹配公式里常顺手带一句画线或标记，报错就等于"网上下来的公式一条都跑不了"；
忽略它、并把这件事说清楚，用户拿到的才是"能用的那部分条件"。

## 三、不支持（给中文原因 + 替代写法，**与"未知函数"分开**）

| 写法 | 界面会怎么说 | 能换成什么 |
|---|---|---|
| `WINNER(...)` | `WINNER 需要筹码分布数据（每个价位的持仓成本），本地没有这份数据。` | `换手率>5 AND V>MA(V,5)*1.5` 这类近似 |
| `COST(...)` | `COST 需要筹码分布数据（成本分布），本地没有。` | 用价格与均线近似，例如 `C<PRE*0.95` |
| `C#WEEK` / `C#MONTH` | `跨周期写法（#WEEK / #MONTH 这类）本引擎不支持：只按日线计算` | 改写成日线等价表达（"近 5 日"用 `COUNT(条件,5)`）；真周线要先做多周期引擎 |
| `"公式名.指标"` | `引用其它策略（"XXX.YYY"）本引擎不支持：本地没有共享的策略库` | 把被引用那条的算式抄进来，或直接用内置的 `MACD / KDJ / RSI / BOLL` |

后两条是**专门拦下来的**：`#` 在本引擎里是注释符，若照注释处理，`C#WEEK` 那一行会被**静默吃掉**
（表现是"公式能编译、结果就是不对"）；`"公式名.指标"` 若不拦，会被当成普通字符串、以"字符串不能参与运算"收场
（让人以为是引号写错了）。两者都**只认特定形状**：普通的 `# 说明:` 注释、普通字符串照旧可用。

## 四、与通达信的口径差异（逐条，都是"名字一样、数不一样"）

| 通达信里的它 | 本程序里的它 | 碰到时程序会怎么说 |
|---|---|---|
| `FINANCE(...)`：流通股本 / 总股本等财务项 | **≡ `流通市值`（亿元）**，参数随便写都一样 | `⚠️ 注意：本程序把 FINANCE(...) 按「流通市值（亿元）」处理 —— 与通达信口径不同（通达信里它是流通股本/总股本这类财务项，本地没有财报数据）；拿它当股本用的策略结果会偏。` |
| `DYNAINFO(...)`：盘中动态行情某字段（17=量比…） | **≡ `量比()`（倍）**，参数（编号）怎么写都一样，窗口固定 5 日 | `⚠️ 注意：本程序把 DYNAINFO(...) 按「量比（倍）」处理 —— 与通达信口径不同（它本体是盘中动态行情，本地只有收盘后的日线）；写成 DYNAINFO(其它编号) 也一样按量比算。` |
| `INBLOCK('板块名')`：是否属于某板块 | **≡ `热门行业`（最近 3 日上榜次数 0~3）**，不做板块名匹配，参数不参与计算 | `⚠️ 注意：本程序把 INBLOCK('板块') 按「热门行业（最近 3 日上榜次数 0~3）」处理，不做具体板块名匹配 —— 与通达信口径不同；写 INBLOCK('xx')>0 就是「上过热门榜」，想更严可以写 >1 或 >=2。` |
| 涨幅 / 换手常写成小数（0.03） | **一律百分数**：涨幅 `3.2` = +3.2%，换手率 `5` = 5%（`换手率` / `现涨幅` / `现换手` 都是） | 不报错但结果会差 100 倍：写 `现涨幅>=1 AND 现涨幅<=5` 才是"涨 1%~5%"，别写 `<=0.05` |
| 画图语句在图上真的画出来 | **整句忽略**，只记一条 note | `ℹ️ 第 N 行的画图语句 … 已忽略（画图对筛选没有影响）` |
| `C#WEEK` / `C#MONTH` 跨周期 | **不支持**，本引擎只按**日线**计算 | `第 N 行第 M 列：跨周期写法（#WEEK / #MONTH 这类）本引擎不支持：只按日线计算（把周期条件改写成日线上的等价表达…）` |
| `"公式名.指标"` 引用别的公式 | **不支持**，本地没有共享的策略库 | `第 N 行第 M 列：引用其它策略（"XXX.YYY"）本引擎不支持：本地没有共享的策略库` |

## 五、本地数据口径带来的限制（不是公式写错）

1. 需要实时快照的 **6 个字段**（`流通市值` / `换手率` / `现价` / `现涨幅` / `现量比` / `现换手`）
   只有**盘中运行时**才取得到，收盘后条件一律不成立 → 可能一只都选不出来。
   程序会怎么说：`⚠️ 需要实时快照的字段（流通市值 / 换手率 / 现价 / 现涨幅 / 现量比 / 现换手）现在都取不到（没有行情快照），用到它们的条件一律不成立 —— 所以可能一只都选不出来。交易时段再试…`
   另外**盘中那四个字段没有历史、不能回测**（快照只有"当下"一个值）：`⚠️ … 非交易时段取不到（条件不成立）；没有历史、不能回测`。
2. `涨停天数()` / `连板()` 读的是**逐日同步攒出来的**本地涨停池，早期日期读到 0。
   程序会怎么说：`⚠️ 注意：连板() / 涨停天数() 读的是本地涨停池（逐日同步攒的），早期日期会读到 0 —— 历史越早，信号越可能偏少。`
3. **`主力净额` / `主力净占比` / `近5日主力净额` 只有「自选标的」才有值**（2026-10-08 主人定的口径：
   "只按照自选标的来采集资金流"）。数据由日更那一趟用东方财富公开接口采自选那几十只，
   写进本地 `fund_flow` 表；**别的票这三个字段一律是缺值，而引擎的规矩是"缺值 = 条件不成立"**
   —— 所以**一条用了 `主力净额>0` 的策略，只会从自选标的里出票**。这不是 bug、也不是副作用，
   是这条采集口径的必然结果（全市场采集要每天给 5000 多只各存一行资金流，那不是主人要的）。
   三条边界要知道：
   * **当天刚加进自选的票要等下一轮日更**才有资金流（采集挂在日更上，不是加自选就立刻采）；
     在那之前界面上的「资金流」那一行写的是 `—（还没采集，日更时会自动采）`；
   * 采集是**增量**的，改大 `fund_flow_days` 不会把过去的资金流补回来；
   * 停用（`enabled=0`）的自选标的**照样采**（那个开关管的是"要不要盯它"，不是"要不要它的数据"）；
   * **这三条没有历史**：它们与 `流通市值` / `换手率` 一样，在引擎里只有**最后一根 K 线**上有值，
     所以【成绩单】/回测那条路里一律是缺值（不会产生任何历史信号）——
     本地 `fund_flow` 表里虽然存着最近若干天的序列，把序列铺进引擎是另一件事。
   程序会怎么说：不会报错 —— 表里没有这只票就是字段缺值、条件不成立（**不编 0**：
   0 的意思是"主力不买不卖"，与"没有这个数"是两件事）。

4. **竞价那三个字段只有同花顺接口给、而且只有 9:15–9:30 取得到**（2026-10-11 加）：
   `竞价匹配额` / `竞价匹配量` / `竞价未匹配量` 来自同花顺的集合竞价端点（`a-share/auction/snapshot`），
   所以有两条硬边界：

   * **要有 Key**：没配 `hithink_api_key`（或环境变量 `HITHINK_FINANCE_API_KEY`）时一个请求都不发，
     字段缺值 → 用到它们的策略一只都不出；公开行情源（腾讯/新浪/东财）**拿不到**竞价撮合数据；
   * **只有 9:15–9:30**：9:15–9:25 是撮合中、9:25–9:30 接口给的还是当天的终态；
     其余时刻接口回 `closed/not_ready`（"现在没有竞价数据"，那是**正常状态**不是错误）→ 字段缺值。

   程序会怎么说：
   `⚠️ 需要集合竞价的字段（竞价匹配额 / 竞价匹配量 / 竞价未匹配量）现在取不到：它们只有 9:15–9:30（集合竞价）才有 —— 现在是 14:20。用到它们的条件一律不成立，所以可能一只都选不出来。`
   （没配 Key 时那句会直接指路：`…只有同花顺接口给（需要 Key），而当前没配 Key…去「系统设置 → 数据来源」把同花顺那一行的 Key 填上`。）
   **这三条同样没有历史、不能回测**（竞价只有"当下"一份）。

## 六、报错时怎么判断"是不是装了旧包"

【校验】报"未知函数"时，提示末尾会带上**本程序的版本号与函数个数**，例如
`（本程序 v1.9.1，策略引擎支持 80 个函数）`；「关于软件」里也有同一行信息，点【复制版本信息】就能贴出来。
看一眼这个数字就知道是策略写错了、还是手上是旧包，不用来回问版本。
