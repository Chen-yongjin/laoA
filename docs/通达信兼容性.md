# 通达信（TDX）公式兼容性清单

用户要求（2026-09-21）：「我要的是**通达信公式进来直接能跑**」。

这份清单说清三档：**支持的**（粘进来就能用）、**忽略的**（不影响选股，但界面会提示"已忽略"）、
**不支持的**（会给出中文原因，不会崩、也不会静默算错）。

> 本页由 `tests/test_tdx_compat.py` 的用例守着：每一档里提到的写法都有对应用例，
> 谁改坏了哪一条，测试立刻红。

## 一、支持（直接可用）

**语法**

| 通达信写法 | 说明 |
|---|---|
| `;` 语句分隔 | 既可一行一句，也可整条公式写在一行（`A:=1; B:=2; A>B;`），引号内的 `;` 不受影响 |
| `:` 输出线 | `MA5:MA(C,5)` 照收（选股用不到画线，所以它等同于定义变量） |
| `:=` 中间变量 | 与通达信一致 |
| `{}` 注释、`//`、`#` | 三种注释都认 |
| `<>` | 表示"不等于"（内部按 `!=` 处理） |
| 全角标点 | `（），：；＞＜＝＋－＊／！％．“”‘’` 全部当半角处理 |
| `AND / OR / NOT`、`&& / || / !` | 大小写都认 |

**字段**

`C / O / H / L / V / AMOUNT / PRE / INDUSTRY`，以及本项目特有的
`流通市值`（亿元）、`换手率`（%）、`热门行业`（最近 3 日上榜次数 0~3）、
`ST / 科创 / 北交所 / 沪市 / 深市 / 创业板`（0/1 标记）。
别名：`CLOSE / OPEN / HIGH / LOW / VOL / VOLUME`。

**函数**（75 个）

- 均线/平滑：`MA EMA EXPMA SMA DMA WMA`
- 引用与窗口：`REF HHV LLV HHVBARS LLVBARS SUM COUNT SUMBARS BARSCOUNT BARSSINCE`
- 条件：`EXIST EVERY BETWEEN RANGE FILTER UPNDAY DOWNNDAY NDAY LONGCROSS VALUEWHEN LAST CROSS NOT`
- 统计与回归：`STD STDP VAR AVEDEV SLOPE FORCAST`
- 指标：`DIF DEA MACD RSI KDJ(RSV/K/D/J) BOLL UB LB OBV WR CCI`
- 数学：`ABS MAX MIN IF IFF POW SQRT LOG LN EXP MOD INTPART ROUND CEILING FLOOR SIGN`
- 涨跌停价：`ZTPRICE DTPRICE`（打板/回踩类公式常用）
- 代码/名称判定：`CODELIKE('300')`（代码前缀）、`NAMEINCLUDE('ST')`（名称包含）——都是**逐票恒定的 0/1**，可以直接进 `NOT(...)` / `OR`
- **`FINANCE(...)` → 按本项目的 `流通市值`（亿元）处理**、**`DYNAINFO(...)` → 按本项目的 `量比`（倍）处理**、
  **`INBLOCK('板块')` → 按本项目的 `热门行业`（最近 3 日上榜次数 0~3）处理**（口径见下面三条说明）
- 本项目特有（数据来自本地库）：`涨停天数 连板 量比`

**几个容易算错的点**（实现里都按通达信口径）：

- `SMA(X,N,M)` 是**加权递推** `Y=(M*X+(N-M)*Y_prev)/N`，**不是** N 日简单平均；
  KDJ 里 `K:=SMA(RSV,3,1)` 用的就是这个语义。
- `HHVBARS(X,N)` 返回"最高值距今多少根"（0 = 就是本根）。
- `BETWEEN(X,A,B)` 不要求 A<B，谁大谁小都认。
- 小技巧：排除板块时，`NOT(CODELIKE('300') OR CODELIKE('688') OR ...)` 那种长写法
  可以换成本项目自带的板块标记：`创业板=0 AND 科创=0 AND 北交所=0`（更短，而且一眼看懂）。
- ⚠️ **`INBLOCK('板块')` 也是按本项目口径实现的**：本地没有板块成分表，也不做板块名匹配 ——
  **它的值就是 `热门行业`（0~3）**，参数（板块名）随便写、不写都一样。
  网上那类公式几乎都写 `INBLOCK('xx')>0`（属于就选中），而次数 >0 正好就是「上过热门榜」，
  语义天然对得上；想更严可以写 `>1` 或 `>=2`。【校验】里有一条提醒说明这一点。
- ⚠️ **`DYNAINFO(...)` 也是按本项目口径实现的**：本地没有盘中动态行情，
  而写这类公式的人十有八九是要量比，所以**它的值就是 `量比()`（倍）**，
  参数（通达信里那个"取哪个字段"的编号）怎么写都收下、结果都一样。
  **与通达信不同**（那边取的是盘中快照字段）——【校验】里同样有一条提醒。
- ⚠️ **`FINANCE(...)` 是按本项目口径实现的**：本地没有财报数据，而写这类公式的人十有八九是想按市值筛，所以**它的值就是 `流通市值`（亿元）**（参数怎么写都收下）。**与通达信不同**（那边是流通股本/总股本这类财务项，单位也不同）——拿它当股本用的公式结果会偏，【校验】里会给一条提醒说明这件事。
- `ZTPRICE(昨收, 比例)` / `DTPRICE(昨收, 比例)`：第二个参数是**比例小数**
  （`0.1` = 10%，不是 `10`），**省略时按 10%**；取整按**这只票所属板块**——
  北交所是涨停向下截断、跌停向上取整，其余板块四舍五入到分
  （规则只在 `src/laoa_trader/price_limits.py` 一处定义，日更判涨停用的是同一套）。
- 窗口不足时结果一律是**缺值**（不产生信号），不会拿更短的窗口凑一个数。

## 二、忽略（不影响选股，界面会写明）

| 通达信写法 | 处理 |
|---|---|
| 画图语句 `DRAWICON / DRAWTEXT / DRAWKLINE / STICKLINE / POLYLINE / DRAWBAND / FILLRGN / VERTLINE / HORLINE / PARTLINE …` | **整句跳过**，校验结果里提示"第 N 行的画图语句已忽略" |
| 样式修饰 `,COLORRED / ,LINETHICK2 / ,NODRAW / ,CIRCLEDOT / ,SHIFT3 …` | 吃掉，提示"已忽略样式修饰" |

为什么是忽略而不是报错：通达信的选股公式里常顺手带一句画线或标记，
报错就等于"网上下来的公式一条都跑不了"；忽略它、并把这件事说清楚，
用户拿到的才是"能用的那部分条件"。

## 三、不支持（会给中文原因，而且**与"未知函数"分开**）

碰到这些时，【校验】给的是**专门的中文说明 + 替代写法**（带行号列号），
**不是**那句干巴巴的「未知函数」—— 后者会让人以为是打错字，然后一直在函数名上较劲。

| 写法 | 提示里会说什么 | 能换成什么 |
|---|---|---|
| `WINNER(...)` | 需要筹码分布数据，本地没有 | 用换手率与量能做近似，例如 `换手率>5 AND V>MA(V,5)*1.5` |
| `COST(...)` | 需要成本分布（筹码）数据，本地没有 | 用价格与均线近似，例如 `C<PRE*0.95` |
| `C#WEEK` / `C#MONTH` | 跨周期不支持，本引擎只按**日线**计算 | 改写成日线上的等价表达（"近 5 日"用 `COUNT(条件,5)`）；要真周线得先做多周期引擎 |
| `"公式名.指标"` | 引用其它公式不支持，本地没有共享公式库 | 把被引用那条的算式直接抄进来，或用内置的 `MACD/KDJ/RSI/BOLL` |

> ⚠️ 跨周期那条是**专门拦下来的**：`#` 在本引擎里是注释符，若照注释处理，
> `C#WEEK` 那一行会被**静默吃掉** —— 表现是"公式能编译、结果就是不对"，
> 那是所有问题里最难查的一种。所以只认后面的周期关键字（`#WEEK`/`#MONTH`/`#MIN5`…），
> 普通的 `# 说明:` 注释照旧可用。

## 三点五、怎么判断「我是不是装了旧包」

【校验】报「未知函数」时，提示末尾会带上**本程序的版本号与函数个数**，例如
`（本程序 v1.1.0，公式引擎支持 71 个函数）`；「关于软件」里也有一行同样的信息，
点【复制版本信息】就能贴出来。

**为什么要专门写这一句**：旧版本的可用函数清单很短（例如只有 19 个），新版本是 71 个 ——
用户报「未知函数 FINANCE」时，作者看一眼这句话就知道是公式写错了、还是他在用旧包，
不用来回问版本。

## 四、写公式时可能踩到的两条"本地口径"

1. `流通市值` / `换手率` 来自**实时快照**：非交易时段（或没配同花顺 Key）取不到，
   用到它们的条件一律不成立 → 可能一只都选不出来。这是数据口径，不是公式错。
2. `涨停天数()` / `连板()` 依赖每天同步的涨停池数据，早期日期会读到 0。
