# 老牛选股（Windows 单机版）验收清单 · v1.2.0

按页签/功能分组。**判据写在条里**：点哪里、看到什么、正确的结果是什么。

## 怎么用这份清单

- **一条一条勾，别跳**。勾得上就是过；**勾不上的就是 bug**。
- 勾不上时，把这条**连同当时屏幕上看到的东西**一起发回来：① 这条的标题文字；
  ② 屏幕上**原样**的提示/运行状态那行字（照抄或截图，**别转述** —— 转述会丢掉关键措辞）；
  ③ 版本号（见文末「报障三件套」）。
- **有些条目"看着不对"其实是设计如此**，条里会写明「设计如此」「不是 bug」——
  这类也要勾，判据是"现象与这里写的一致"，不是"结果好看"。
- 边界情况（**非交易时段、休市日、没配 Key、快照取不到、断网、日历没同步**）写在对应条目里，要在那个状态下才能验。
- **绝不要**因为"没数据/没行情"就记成通过：写了该显示 `—` 的，显示 `—` 才算过；
  显示 `0` / `0.00亿` / `0.00%` 一律算 bug。

> 本清单以**当前代码**为准（按钮名、列名、提示语都对着代码核过）。
> 数据目录默认 `%LOCALAPPDATA%\LaoATrader\data`；配置与授权在 `%APPDATA%\LaoATrader\`。

- [ ] **Key 写错/过期也要能落到公开源**：把 `hithink_api_key` 填成一段乱码 → 重开 → 界面**仍然有数**，tooltip 里能看到 `同花顺凭据不可用，本次已改走免 Key 公开行情源…`。

### 4.3 「本次口径」：盘中实时 vs 日 K 线（关键行为）

- [ ] **这是内置规则、没有开关**：界面上**没有**"盘中选股用不用实时数据"的勾选框。规则是：**开盘时间里跑的选股就是实时口径，不是开盘时间用日 K 线**。
- [ ] **走实时口径要同时满足四道闸门**（顺序即代码顺序，任一不成立就退回日 K 并**说清是哪一条**）：
      ① `cfg` 拿得到数据来源；② 现在是**开盘时间**（09:30–11:30 / 13:00–15:00，北京时间，闭区间）；
      ③ 库里有日线，且**最新行情日早于今天**（`库里已经有 <today> 这根 K 线了` 就退回日 K）；
      ④ 今天在库里的**交易日历**里。外加一条数据条件：**取得到实时快照**。
- [ ] **「本次口径」这句话在三处都要显示**（少一处就是 bug）：① **编辑器提示区**（点【运行】后，它是提示区的**第一行**）；② **结果页**（点【开始选股】后，写在结果提示的**最后一行**）；③ **结论**（主窗口运行状态里那句"完成：行情日 … 池子 N 只，📊 本次口径：…"）。
- [ ] 开盘时间跑 → 三处都写着 **`📊 本次口径：盘中实时（HH:MM，用现价拼出今天 YYYY-MM-DD 这根 K 线）`**。
- [ ] 非开盘时间跑 → 三处都写着 **`📊 本次口径：日 K 线（最后一根 <日期>；<原因>）`**，原因形如 `现在 10:03 不是开盘时间`（午休/收盘后）、`今天不在交易日历里（休市）`、`库里已经有 2026-09-25 这根 K 线了`、`本地还没有日线数据`。
- [ ] **这两句话是纯文本**（不是 markdown）：提示区里**不出现星号**（写 `**加粗**` 会原样显示成两个星号）。
- [ ] **开盘时间但取不到实时快照** → 退回日 K，并且**必须写明** `⚠️ 现在是开盘时间，本该按实时数据选股，但取不到实时快照 → 本次已退回日 K 线口径（收盘数据）。用到「现价 / 现涨幅 / 现量比 / 现换手」的条件不会成立；市值/换手也一样取不到。…`
      —— 这是**告知**（结果页与结论上看得见），**不是**把这次选股判成失败。
- [ ] **休市日特判**：周末/节假日 09:30–15:00 之间点【运行】也走**日 K 口径**（只看钟点会把上一个交易日的快照当成"今天的盘"，选出一批 `pct=0` 的假信号）。
- [ ] ⚠️ **边界（日历没同步时）**：判"今天是不是交易日"靠本地库的 `trading_calendar` 表；**表为空、或库读不到时按"交易日"处理**（fail-open），此时周六盘中也会走实时口径 —— 判据是那时口径提示里写的是"盘中实时"而**不是**"休市"，这是设计如此。
- [ ] **同一份策略在盘中和收盘后会选出不同的票**，这是正常的；判据就是上面那句口径说明能解释它。

### 8.3 免 Key 那一路（公开源：能看、能留档；不能回补历史、不能选股）

- [ ] **点【下载数据】→ 被拒绝 + 指路配置文件 + 说清"能用什么、选股为什么要 Key"**（设计如此，别记成 bug）：预期页内点亮 `❌ 完整历史数据要同花顺 API Key（每个用户自己申请一个）：在 config.toml 里写 hithink_api_key = "你的Key"，或设环境变量 HITHINK_FINANCE_API_KEY，然后重启程序（申请地址见上面那行的 …）。没 Key 时能用的：实时行情（自选股池/持仓监控）与大盘概览 —— 每天也会自动把当天的行情与涨停池写进库；但选股要 Key：数据自检要求「复权事件」与「行业归属」齐备（这两样只有同花顺那条路给得到），缺了就拒绝选股（就是不让程序拿算错的复权价去选票）`；并 toast `❌ 选股要同花顺 Key · 没 Key 时行情与大盘概览可用 · 见【系统设置】`；**没有任何进度条出现**（因为压根没开始下载）。
- [ ] **点【刷新数据】→ 免 Key 日更是通的**：运行状态里出现 `免 Key 日更：正在取全市场快照（约 1 分钟）…`（**先不写库**，取不到就一个字节都不写），完成后一句话形如 `2026-09-18：写入行情 N 行，涨停池 M 行，代码/名称 K 条`。

- [ ] **"历史就是一天天攒的"要能看出来**：多跑几天（或改系统日期重跑）→ 这只票的行数一天天增加；**当日快照补不回中间缺的天**，日志里会如实写 `有 X 只票的上一根日线不是最近交易日（中间缺天）…` —— 那是**如实上报缺口**（你不是每天都开机），不是错误。
- [ ] **拿不到的字段是 NULL 而不是 0**：查当日 `limit_up_pool` 的行，`order_amount`（封单额）/ `first_limit_up_time` / `last_limit_up_time` / `reason_type` / `currency_value` / `is_again_limit` / `is_new` 应当**全为 NULL**（编个 0 出来会让 `连板()>=2` 误判）。
- [ ] **停牌不写假 K 线**：当日成交量为 0 的票不应在 `stock_daily_raw` 里出现当日行。
- [ ] **`high_days` 是自己滚出来的**：当日涨停池里某只票若在前一个交易日的池子里，它的 `high_days` = 前值 + 1，否则为 1。
- [ ] **没 Key 时行业归属永远是空的（因此"板块"列是 `—`）**：`stock_basic.industry` 全为 NULL；建池时日志出现 `热门行业为空（缺行业/涨停/历史数据），本次不做过滤` —— 这是**放行**（不过滤），不是失败。

      预期现象：界面**明确拒绝**并把页面切到「系统设置」，提示形如 `⚠️ 本地无可用历史数据（缺少复权事件（分红/送股/配股），后复权价会算错，不能算就绪）；请先下载：在界面【系统设置】页点【下载数据】…`；命令行 `--cli --once` 输出同样原因且**退出码非 0**。

### 8.4 自动运行时间（**默认不跑**）

## 发现问题的报障三件套

勾不上任何一条时，把下面三样**一起**发回来，比只描述现象快得多。

**① 版本号（一句就分清是不是旧包）**

```bat
老牛选股.exe --version
```

输出是四行，整段贴过来：

```
老牛选股助手 1.2.0
构建形态：Nuitka 编译版（原生 exe）
程序位置：<你的安装目录>
策略引擎：支持 N 个函数
```

（也可以点界面右上角【关于软件】→【复制版本信息】，剪贴板里的名称/版本/版权三行同样管用。）

**② 口径提示那句话（决定"这次结果能不能用"）**

把**当时屏幕上**那句 **`📊 本次口径：…`** 原样抄下来 —— 它出现在三处，抄任意一处都行（编辑器提示区 / 选股结果页 / 主窗口运行状态那句结论）。它只有两种：

- `📊 本次口径：盘中实时（HH:MM，用现价拼出今天 YYYY-MM-DD 这根 K 线）`
- `📊 本次口径：日 K 线（最后一根 <日期>；<原因>）`

**为什么必须要这一句**：同一份策略在盘中（实时口径）和收盘后（日 K 口径）选出的票本来就不一样；没有这句话，就没法判断"选出 3 只 / 7 只"是程序不稳定还是口径不同。顺带把提示区/结果页上**其它几句中文**也一起抄（尤其是"快照取不到""拒绝选股"那类）。

**③ 日志与自检报告路径**

```bat
:: 自检报告（路径/依赖/凭据/数据三态结论）——跑完会同时写一份到磁盘
老牛选股.exe --cli --doctor

:: 日志（下载/选股/提醒的每一步都写在这里）
type %LOCALAPPDATA%\LaoATrader\data\logs\laoa-trader.log
```

- **自检报告落盘**：`%LOCALAPPDATA%\LaoATrader\data\logs\自检报告.txt`（跑完 `--doctor` 后控制台最后一行会写 `自检报告已写入：<完整路径>`）。
- **日志**：`%LOCALAPPDATA%\LaoATrader\data\logs\laoa-trader.log`（2 MB 轮转、保留 3 份：同目录下的 `.1` / `.2` / `.3`）。
- **数据目录**：`%LOCALAPPDATA%\LaoATrader\data`（默认；里面有 `trader.db`、`dumps\`、`logs\`、`cache\`）。**删掉 `trader.db` 就等于"重新来一遍"**（配置不在这里，不会被删）。
- **配置与授权**：`%APPDATA%\LaoATrader\config.toml` 与 `%APPDATA%\LaoATrader\license.json`（**不在**数据目录里；放在这里，覆盖安装不会丢）。
- 界面里也能直接看到这两条路径：「系统设置 → 数据来源」最下面**只读**的数据目录与日志路径，点【复制路径】一次复制两条。

**报障时最有用的三样**：**现象截图 + 日志尾部（几十行就行）+ `--doctor` 输出**。

> 概览页报错时先看两处、不用翻日志：① 页脚那行小字的"更新于"——`—` 表示这一趟一项都没取到（程序**故意**不写取数时间，免得你以为是刚取到的数）；② 概览块下面那行 ⚠️ 提示（鼠标停在页面上任一处的 tooltip 里是同一份文本）。
