# Windows 打包与分发给别人用的完整教程

> 两条路径先分清楚：
> - **你要打包** → 需要 Python 3.11（本文第一~五节）
> - **别人只是用你打好的 exe** → **什么都不用装**（本文第六节）
>
> 全部命令都在 **项目根目录**（就是你复制过去的那层，里面有 `pyproject.toml`、`src`、`build`、`tests`）执行。

---

> **默认只导入 3 年历史**（同花顺 dump 仍是 10 年数据集，只是导入时按 `history_years` 过滤）：
> 约 300 万行，库更小、首次导入更快（**下载量不变**，dump 还是要整个下），**专为分发给别人**；
> 收到的人想要长样本，把 `config.toml` 的 `history_years` 改成 `10` 重新下载即可。
>
> **分发出去之后，运行时间由每个人自己在界面里定**：打开程序 → 「设置」页 → 「自动运行」→
> 改主跑/补跑时间（默认 16:00 / 19:15）→ 保存即生效、不用重启；状态栏会显示"下次自动运行"。
> 所以打包时**不用**替别人把时间写死，默认值就是收盘后 16:00。

## 一、准备一台 Windows 打包机

| 要求 | 说明 |
|---|---|
| 系统 | Windows 10 / 11，64 位 |
| 磁盘 | 至少留 **5 GB**（依赖 + 打包中间产物 + 产物） |
| 网络 | 能访问 pypi.org（装依赖）；**打包不需要同花顺 Key** |
| Python | **3.11**（3.12/3.13 未验证，请用 3.11） |

> 打包必须在一台真正的 Windows 上做：PyInstaller 不能跨平台（Linux/macOS 上打不出 exe）。

---

## 二、安装 Python 3.11

**方式 A（推荐，图形界面）**

1. 打开 <https://www.python.org/downloads/release/python-3119/>
2. 下载 **Windows installer (64-bit)**
3. 安装第一步的界面底部，**务必勾选 `Add python.exe to PATH`**（不勾的话后面 `py`/`python` 命令会找不到）
4. 选 `Install Now`，等它装完

**方式 B（命令行）**

```bat
winget install Python.Python.3.11
```

**验证**（新开一个命令行窗口）：

```bat
py -3.11 --version
:: 应输出：Python 3.11.x
```

---

## 三、把项目复制到打包机

1. 把整个 **`laoA` 文件夹**复制到 Windows（例如 `D:\laoA`）
2. **不要**把下面这些带过去（它们是 Linux 产物或本机数据，带了反而出错）：
   - `.venv/`（Linux 二进制，600MB 且无法在 Windows 用）
   - `dist/`、`build/build/`（打包中间产物）
   - `config.toml`（**含你的 API Key，别外传**）
   - `*.db`、`*.parquet`（几个 GB 的数据，运行时自己会下）
   - `__pycache__/`、`.pytest_cache/`、`*.tmpdir`
3. 确认目录里有：`pyproject.toml`、`src\laoa_trader\`、`tests\`、`build\build.bat`、`build\laoa_trader.spec`

> **路径建议**：放在**不带中文和空格**的路径下（例如 `D:\laoA`）。中文路径在少数打包环节可能出问题，避开可以少踩一个坑。

---

## 四、（建议）先跑测试，确认环境没问题

```bat
cd /d D:\laoA
py -3.11 -m venv .venv
.venv\Scripts\python -m pip install -U pip
.venv\Scripts\pip install -e ".[dev]"
.venv\Scripts\python -m pytest tests -q
```

**期望结果：`1086 passed`**（Windows 上 PySide6 与 pyarrow 都装齐，不会 skip）。

**为什么先跑测试**：如果这里就报错，说明是"环境问题"（依赖装不上、Python 版本不对），跟打包无关 —— 先解决它，比带着问题去打包省时间。测试全程**不联网、不需要同花顺 Key**。

---

## 五、打包

```bat
build\build.bat
```

脚本会自动做四件事：

1. 检查 Python（没有会打印中文安装指引并退出）
2. 创建 `.venv`（若不存在）
3. 安装依赖（含 PyInstaller）
4. 执行 `pyinstaller --noconfirm --clean build\laoa_trader.spec`

**预期耗时**：首次 **3~8 分钟**（主要卡在 PyInstaller 分析 pandas/pyarrow/PySide6）。

> **exe 图标**来自 `src/laoa_trader/assets/icon.ico`（多尺寸 ICO，由 `python build/make_icon.py`
> 生成、`build/laoa_trader.spec` 自动接上）—— **改了图标要重新打包才会生效**：
> 只替换 `assets/` 里的文件、不重新打包，用户拿到的 exe 还是旧图标。
> 图标文件缺失不会让打包失败（spec 会打印一句提示并退回 PyInstaller 默认图标）。

**产物**：

```
dist\老牛选股助手\          ← 整个目录就是分发单位，约 300~500MB
├─ LaoniuTrader.exe          ← 双击这个
└─ _internal\               ← 依赖与动态库（不要删、不要单独移动 exe）
```

### 为什么是"目录版"而不是单文件 exe

| | 目录版（onedir，当前默认） | 单文件（onefile） |
|---|---|---|
| 启动速度 | 快（约 1~3 秒） | 慢（每次解压到临时目录，10~30 秒） |
| 杀软误报 | 较少 | **明显更多** |
| 分发 | 压缩整个目录 | 一个文件 |
| 结论 | ✅ 推荐 | 除非必须单文件，否则别用 |

要做单文件：把 `build\laoa_trader.spec` 里 `EXE(...)` 的 `exclude_binaries=True` 与 `COLLECT(...)` 调整成 onefile 形式，或在 `build.bat` 里加 `--onefile`（不推荐）。

## 六、第一次运行（你或别人拿到 exe 后）

**目标机器什么都不用装**（不需要 Python、不需要 Docker、不需要连你的 NAS）。

1. 解压 `老牛选股助手` 目录到任意位置（路径里别带空格）
2. 双击 `LaoniuTrader.exe`
3. 程序会先做**数据自检**（纯本地、秒级），三选一：
   - ✅ **就绪** → 直接进主界面（状态栏显示"本地数据就绪：503 万行 / 最新 2026-09-11"）
   - ⚠️ **落后几天** → 进主界面 + 状态栏提示，并按设置自动后台补增量
   - ❌ **没有数据** → 弹出**首次向导**：显示原因 → 填/确认 API Key 与数据目录 → 点【开始下载】
4. **下载中断不用重来**：dump 是几百 MB、下载链接只活约 5 分钟，程序做了
   **断点续传 + 过期自动重签 + 重试**（默认 5 次，日志会写"从第 X MB 继续"）；
   网络断了就重开程序再点一次下载，会从断的地方接着下。详细排查见 README 的
   「下载中断了怎么办？」
5. 首次下载约 **8~15 分钟**：同花顺的 dump 固定是 10 年数据集，程序**只导入最近 3 年**
   （约 300 万行，分发给别人更轻）；有进度条、**可取消**、**中途关掉下次会续传**。
   想要 10 年长样本：把 `config.toml` 的 `history_years` 改成 `10` 后重新下载（库约大一倍）
5. 下载完成后会自动跑一次【开始选股】；之后：
   - 每天 `19:15` 自动跑日更（增量 → 策略 → 建池 → 按你的通知设置推送）
   - 交易时段 `09:30-11:30 / 13:00-15:00` 按间隔（默认 60 秒）盯池提醒
6. 配置与数据位置：
   - 配置：程序目录下的 `config.toml`（首次运行自动生成，可改参与选股的公式/通知方式/阈值）
   - 数据：`%LOCALAPPDATA%\LaoATrader\data\trader.db`（删掉它重启会重新进下载向导）
   - 日志：`%LOCALAPPDATA%\LaoATrader\logs\laoa-trader.log`
   - **公式：exe 同级的 `formulas\` 目录**（纯文本，用记事本就能改；第一次打开
     「公式选股」页时会把随包分发的示例公式复制进去）。用户自己写的公式放这里 ——
     备份、发给别人、换机器都只是拷这个目录；想换位置就设环境变量
     `LAOA_TRADER_FORMULAS` 指向别处。**别去 `_internal\formulas` 里改**：
     那是程序解包出来的只读副本，升级/重装会被覆盖

### 分发时注意

- **压缩 `dist\老牛选股助手` 整个目录**再给别人；不要只发 exe（少了 `_internal` 起不来）
- **不要把自己的 `config.toml` 一起发**（里面有你的同花顺 API Key）；让对方自己填
- **不要把自己的 `formulas\` 一起发**（那是你自己的公式；不想要的话删掉它，
  程序下次打开「公式选股」页时会把示例公式重新放进去）
- 对方需要：**能上网** + **自己的同花顺 API Key**（在 <https://fuyao.aicubes.cn/admin> 申请）
- 首次运行会被杀软/防火墙问一次，允许即可（程序要联网下数据）

## 七、常见问题与对策

| 现象 | 原因与处理 |
|---|---|
| `py -3.11` 不是内部或外部命令 | Python 没装或没勾 `Add python.exe to PATH`；重装并勾选，或改用 `python` |
| `pip install` 卡住/超时 | 网络或代理问题；可加国内镜像：`-i https://pypi.tuna.tsinghua.edu.cn/simple` |
| 打包报 `ModuleNotFoundError: xxx` | PyInstaller 没自动发现该模块 → 在 `build\laoa_trader.spec` 的 `hiddenimports` 里追加该模块名，重新打包 |
| 运行 exe 报缺 `VCRUNTIME140.dll` | 目标机器缺 VC++ 运行库 → 让对方装 [VC++ 2015-2022 可再发行组件](https://aka.ms/vs/17/release/vc_redist.x64.exe) |
| exe 被杀软删掉/隔离 | 加信任/白名单；或改用目录版（已是默认）；企业环境可考虑代码签名 |
| 界面能开但白屏/排版乱 | 先确认 exe 与 `_internal` 在同级目录且未被移动；高 DPI 异常在 `LaoniuTrader.exe` 右键→属性→兼容性里试"替代高 DPI 缩放" |
| 托盘图标不显示 / 通知不弹 | Windows 设置 → 系统 → 通知，确认允许该应用；托盘图标可能被折叠到隐藏区 |
| 首次下载中途失败 | 重开程序会**续传**（不从头来）；若报"未配置 API Key"去 `config.toml` 填 `hithink_api_key` |
| 用户问"怎么授权/我的机器码是多少" | 让他打开【关于软件】→【授权…】，机器码就在窗口里；他发机器码给你，你用 `python build/keygen.py <机器码>` 算出注册码回给他（**别把 `keygen.py` 打包发出去**） |
| 想不开界面、只用命令行 | `LaoATrader.exe --cli --doctor`（自检）、`--cli --once`（立刻跑一次）、`--cli --pool`、`--cli --market`（大盘概览页那几行）、`--cli --watchlist list` 等 |
| 出问题要我定位 | 发我四样：**完整报错文本 + `--cli --doctor` 输出 + `<数据目录>\logs\laoa-trader.log` + 卡在验收清单第几节第几条** |

## 八、可选：不装 Python 也能出 exe（GitHub Actions）

如果这台 Windows 不方便装 Python，可以把代码放到 GitHub 私有仓库，用 **GitHub Actions 的 Windows 运行器**自动打包：

1. 建私有仓库，把 `laoA` 内容推上去
2. 在仓库里建 `.github/workflows/build-windows.yml`（内容我可以帮你写）：
   - `runs-on: windows-latest`
   - 步骤：`setup-python@v5`（3.11）→ `pip install -e ".[dev]"` → `pytest tests -q` → `pyinstaller build\laoa_trader.spec` → 上传 `dist\LaoATrader` 为 artifact
3. 每次 push 后，在 Actions 页面下载产物 zip

好处：你本机零依赖；坏处：代码要放到 GitHub（含策略与规则，介意的话用私有仓库）。
需要我把这个 workflow 写好，说一声即可。

## 八·五、注册机（作者的签发工具）怎么打包 —— **CI 的包里带一个，分发前删掉**

口径变过一次，两个日期都留着：

- 2026-09-20 用户：「注册机做成可执行文件。不随包分发。」
- 2026-09-21 用户：「直接把注册机打包到程序包里也可以的。」（理由：他正式分发时会**重新打包**）

所以现在的做法是：**CI 出的那个 zip 里带着一个注册机**，文件名故意写成刺眼的
`注册机-作者专用-别分发给用户.exe`（放在 `LaoniuTrader\` 目录里）；你拿包就能直接签码，
**正式发给用户之前把这一个文件删掉**。（CI 里那一步会打一条 `::warning::` 提醒你。）

**为什么它必须能被一眼认出来**：注册机里带着**签发密钥的算法** —— 谁能拿到这个 exe，
谁就能给任意机器码算出注册码，整套授权等于送人。所以：文件名的中文前缀是硬要求，
CI 里还有两条检查（包里必须**恰好一个**、名字必须是那个、不许出现别的 `keygen*`；
同时主程序自己打进的东西里仍然不许混进 keygen —— `laoa_trader.spec` 的 `DATAS`/`COLLECT`
里都没有它），用例 `tests/test_packaging.py` 钉着这两条。

**怎么打（两种都行）**：

```bat
:: 1) 作者本地打包（最快）
pyinstaller --noconfirm --clean build\keygen.spec
:: 产出 dist\keygen.exe —— 单文件，双击即用（onefile；主程序是 onedir，两者取舍不同）

:: 2) 走 CI（不想在本机装环境时）
::    GitHub → Actions → build-windows → Run workflow（**手动触发**）
::    跑完去 Release 页面拿（与主程序同一个页面）：Assets 里的 keygen.exe
```

- **注册机去哪下**（2026-09-21 改）：与主程序**同一个滚动 Release 页面** →
  https://github.com/Chen-yongjin/laoA/releases/tag/latest → Assets → `keygen.exe`。
  直链 `https://github.com/Chen-yongjin/laoA/releases/download/latest/keygen.exe`。
  **为什么改**：注册机原来只走 artifact，而私有仓库的 Actions 存储有硬额度（免费 500MB，
  主包一封就几百 MB），额度一满那一步必失败 —— 手动跑了 workflow 也拿不到东西
  （主人 2026-09-21 实报「keygen 没跑通」）。Release 附件与那份额度是两回事、链接还固定。
- 下载时别看错：**`keygen.exe`（Release 上那一个）与包里的
  `注册机-作者专用-别分发给用户.exe` 都只给你自己**。给用户的包里**必须先删掉**那一个文件
  （用户版 = CI 的 zip 减掉那一个 exe；主 spec 不含它、CI 有两条检查、用例也钉着）。
- 注册机 job 什么时候跑：主人**手动触发**时；另外**改动 `build/keygen.spec` / `build/keygen.py` /
  `src/laoa_trader/licensing.py` / 这个 workflow 自己**的 push 也会自动重发一次
  （免得"注册机该更新了"要靠人记得点一下）。其余 push 不跑，省 runner。

> **CI 上的产物是一个 zip**（`LaoniuTrader.zip`）：里面就是 `LaoniuTrader\` 目录，
> 解压后进目录双击 `LaoniuTrader.exe`。为什么打成单个 zip 再上传：dist 目录里有一万多个
> 小文件（PySide6 / pyarrow），2026-09-21 有过一次「包做好了、整目录上传失败」——
> 单文件上传更稳。

**发版前顺手确认**：解压出来的 `dist\LaoniuTrader\` 里**没有** `keygen.exe`
（清单里也有一条勾选项）。

**将来加壳（用户说等版本成熟再做）**：加壳（VMProtect / Themida / Enigma 之类）能显著
抬高逆向门槛，但会带来"杀软大面积误报 + 体积与启动变差 + 每次改代码都要重走流程"的代价，
所以现在不做。它是**对产物做的后处理**（`dist\keygen.exe` 出来之后再处理），
不用改 spec 里的任何一行。
- 授权状态文件在 `%APPDATA%\LaoATrader\license.json`，**不在安装目录**：
  用户覆盖安装升级不会丢授权（与 `config.toml`、飞书配置同一个道理）。
- `ui.license_dialog` 是**按需导入**的，PyInstaller 静态分析看不到它 ——
  spec 的 `hiddenimports` 里已经写了它（漏了的表现是"本机全绿，exe 里点【授权…】没反应"）。

## 九、打包完成后的自检清单（最短版）

- [ ] `dist\LaoATrader\LaoATrader.exe` 存在，双击能开
- [ ] exe / 窗口标题栏 / 任务栏 / 托盘 / 「关于」页显示的都是**自己那个图标**
      （深蓝底白 A 红折线），不是 PyInstaller 或 python 的默认图标
- [ ] 把 `LaoATrader` 目录**换个位置/换台机器**仍能运行
- [ ] 首次运行进"下载向导"，能下载、能取消、重开能续传
- [ ] 数据就绪后：池子有标的、能复制条件单参数、自选股能加进池
- [ ] **大盘概览页能显示真实数字**：「大盘概览」页签（**第一个页签，启动就停在这**）有涨停/跌停/炸板家数、
      沪深北成交额、涨跌家数，以及 `宽基：` / `情绪：` / `板块：` 三组指数
      （`LaoATrader.exe --cli --market` 打印的是同一份，退出码 0）；
      只在这一页可见时每分钟自动刷新，清空 `hithink_api_key` 后各组显示 `—` 且界面照常可用
- [ ] 通知三路（自己勾选的那些）都能收到；故意改错飞书凭证后 **Windows 弹窗仍正常**
- [ ] 删掉 `%LOCALAPPDATA%\LaoATrader\data\trader.db` 重启 → 回到下载向导
- [ ] 完整验收见 `docs\WINDOWS-验收清单.md`（九节，逐条勾）
