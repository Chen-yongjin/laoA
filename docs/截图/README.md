# 界面截图（docs/截图/）

这 10 张图是**用演示数据生成的**，用于软件介绍与产品网站（`网站/截图/` 是这里的拷贝）。

> **图里的行情全是编的**：股票、价格、涨跌幅、市值、换手、盈亏、消息都为展示界面而造，
> 不是真实行情，也不是匹配推荐或实盘业绩。对外展示时别让人误读成真实成绩。

## 怎么重新生成

```bash
cd <仓库根>
QT_QPA_PLATFORM=offscreen python build/make_screenshots.py     # 出图到 docs/截图/
LAOA_SHOTS_DEBUG=1 QT_QPA_PLATFORM=offscreen python build/make_screenshots.py   # 额外打印三张表的每个单元格
cp -f docs/截图/*.png 网站/截图/                                 # 同步到网站
```

脚本要点（改演示数据时看这里）：

- 运行时会临时改掉 `HOME`/`APPDATA`/`LOCALAPPDATA`，**不会碰真实的配置、自选标的和授权状态**。
- **主界面那 7 张（01~07）不是干抓窗口**，而是合成到一张 1684×936 的"桌面"画布上：
  主窗口贴左上（留 18px 边距 + 投影），**桌宠贴右下角**（透明底直接贴，脚下一点淡影子），
  看起来就是"桌宠站在桌面上陪着主窗口"。桌宠与窗口右侧隔 28px，**不压任何一列**；
  整只都在画布内，不会被裁掉。改窗口尺寸不用动这里（画布由 `_canvas_size` 算出来）。
- 桌宠气泡两处：主界面那几张是「铂科新材 300811 涨停打开」，`09-桌宠提醒.png` 特写是
  「水晶光电 002273 止损提醒」—— 两条都能在演示数据的 `DEMO_ALERTS` 里找到，票也都在自选/持仓里。
- 单张控制在 **400KB 以内**（画布存成 RGB888 不带 alpha，比带通道小一截；当前最大 380KB）。
- 演示行情集中在 `build/make_screenshots.py` 顶部的 `DEMO_STOCKS` / `DEMO_QUOTES` / `DEMO_WATCH` /
  `DEMO_POSITIONS` / `DEMO_SECTORS` / `DEMO_ALERTS` / `DEMO_RESULT`。
- 假行情的注入必须发生在 `MainWindow(cfg)` **之前**（窗口构造时就会启一个行情线程，晚了就被真数据覆盖）。
- 三张表的数字是联动算出来的：现价/涨幅/市值/换手来自 `DEMO_QUOTES`；自选与持仓的盈亏 = `1/ratio − 1`；
  止损位/止盈位 = 成本价 × (1 ∓ `cfg.stop_loss`/`cfg.take_profit`)。
- 大盘概览的涨跌家数、涨停/跌停/炸板、成交额来自假行情源里那 4800 只票和指数行，改只数记得一起改。

## 图目录

`01`~`07` 都是**桌面合成图**（主窗口 + 右下角桌宠）。

| 文件 | 内容 |
| --- | --- |
| `01-大盘概览.png` | 成交与情绪、宽基指数、热门板块（含口径说明） |
| `02-自选标的.png` | 自选 + 策略池合并表，含来源、加入日期、盈亏、盯盘开关 |
| `03-持仓监控.png` | 持仓成本、现价、盈亏、止损位/止盈位 |
| `04-策略匹配-列表.png` | 策略列表与勾选参与匹配 |
| `05-系统设置.png` | 行情源、提醒、桌宠等设置 |
| `06-策略匹配-编辑器.png` | 公式编辑器（左侧写公式、右侧插入函数） |
| `07-策略匹配-匹配结果.png` | 本次匹配结果与「加入自选 / 导出到桌面」 |
| `08-消息列表.png` | 提醒消息列表（独立窗口特写，非桌面合成） |
| `09-桌宠提醒.png` | 桌面宠物特写（透明底素材，非桌面合成） |
| `10-授权窗口.png` | 机器码与注册码（试用 7 天） |
