# 老A选股助手 · 改版方案（按用户给定布局重构）

> 定位：**股票助手**，是行情软件的有效补充 —— 不替代券商客户端，只做"看一眼就知道该干什么"。
> 本文件是改版的**唯一对齐依据**：界面做成什么样、旧功能去哪儿、默认值是多少，以这里为准。
> NAS 服务器版（`/vol4/@apphome/dsh/选股/` 根目录）**一个字节不动**，本次只改 `laoA/`。

---

## 一、标题区（不再是"状态栏 + 一排按钮"）

```
老A选股助手  ·  运行状态：正在下载历史数据 48%（写入行情 62 万行 / 285 万行）   [显示详情] [关于软件]
```

- **软件名称 + 运行状态**在同一行：状态就是"现在在干什么"，下载/刷新/选股/盘中轮询全部显示在这里
  （原来状态、进度条、按钮分散成三行，改成一件事只说一次）。
- **【显示详情】**：点开看完整信息（数据日期、股票数、库大小、下次检查、今日提醒计数、数据目录、日志路径、
  自检阈值）。原来散在状态栏与多处提示里的长期信息都收进这里。
- **【关于软件】**：版本/版权/源码地址/复制版本信息。
- **原则：尽量减少弹窗式提示**。只有"必须让用户做决定"的才弹（目前只剩：缺 API Key 时需要输入 Key）；
  其余一律写进标题区状态 + 通知消息（通知是否发、发哪些，**全部由用户配置**）。
- 标题区**不再放操作按钮**：数据下载/刷新/选股都在各自的页面里（数据在「系统设置」，选股在「策略选股」）。

## 二、五大页签

### TAB 1 全市概览
三块，竖直排列，窄窗口自动换列：

| 块 | 内容 |
|---|---|
| 宽基指数 | 上证 / 深证 / 创业板 / 科创50 / 沪深300 —— 点位 + 涨跌幅（各自按涨跌上色） |
| 情绪指数 | 同花顺情绪类板块指数 + **成交额、涨停家数、涨跌家数**（原来占一整排的 KPI 卡片折成这里的 3 个小条目，不再单开卡片） |
| 热门板块 | 当日**涨停密度**前 12 的行业：涨停家数 / 密度 / 近 5 日行业等权涨幅（就是选股时用的那套"热门行业"口径，摆出来让用户看得见） |

页脚一行：`数据来源：同花顺金融数据服务 · 更新于 HH:MM` + 【立即刷新】。

### TAB 2 自选股池
- **添加入口**：代码 + 备注 →【添加自选】（回车即加）。
- **表格列**：`名称(代码) | 现价 | 涨幅 | 板块 | 来源 | 提醒`
  - **现价 / 涨幅**：实时快照（60 秒轮询）优先；没有实时数据时用本地最新收盘价并标注（`12.34*`）；
  - **板块**：`stock_basic.industry`；
  - **来源**：`策略·<策略名>` / `公式·<公式名>` / `自选` / `策略+自选`（沿用现有 `pool.source_label`）；
  - **提醒**：**今日**该股最新一条盘中提醒（止损/止盈/涨停打开/跌破 5 日线/放量突破/回踩买点/做T/竞价/异动），
    没有就 `—`；鼠标悬浮看完整那句（含触发数字与动作）。
- **交互**（三张表统一）：
  - 悬浮 → 显示备注（有备注的行）；
  - 右键菜单 → 【删除】/【关闭监控】↔【打开监控】；
  - **单击 → 打开雪球个股页**（`https://xueqiu.com/S/SH600000` 这种，复用 `notify/windows.py:to_xueqiu_code()`）。
- 本表**同时**显示策略/公式选出来的票（`来源` 列区分）与手工添加的自选股 —— 这是"池子"的唯一入口。
- 表头右侧一行小字：`共 N 只（策略 M · 自选 K）`。

### TAB 3 持仓监控
- **添加入口**：代码 + 成本价 + 备注 →【添加持仓】；同一行右侧一个复选框 **T策略**（默认关，与「系统设置」里的是同一个开关）。
- **表格列**：`名称(代码) | 成本价 | 现价 | 涨幅 | 盈亏比例 | 止损位 | 止盈位 | 提醒`
  - 盈亏比例 = `(现价 − 成本) / 成本`，涨红跌绿，缺价显示 `—`（不显示 `0.00%`）；
  - 止损位/止盈位 = `成本 × (1 ∓ 止损/止盈比例)`，比例在「系统设置 → 持仓风险」里改；
  - 提醒列口径与自选股池相同。
- 交互同上（悬浮备注 / 右键删除与开关监控 / 单击开雪球）。
- **数量不再出现在界面上**：持仓只记"代码 + 成本 + 备注"（用户给定的字段），
  原来的"数量"字段保留在库里做兼容（详见第五节）。

### TAB 4 策略选股
上下两块：

**（1）策略列表** —— 内置策略与自定义公式**同一张表**：`名称 | 备注 | 状态`
- 内置 5 条固定在内（备注列写明它的证据，例：`两套口径都为正 · B +0.03%(t=1.38)`、
  `⚠️ 只在"开盘买"口径为正`、`⛔ 默认关闭：两套口径显著为负`）；
- 自定义公式追加在后（备注来自公式文件的 `# 说明:`）；
- **单击一行 → 打开编辑**（内置策略只读展示条件说明；公式可改可另存）；
- **右键菜单** → 【启用】↔【关闭】/【删除】（内置策略不可删，只能启停）；公式的启停写回 `enabled_formulas`；
- 【开始选股】：跑所有**启用**的策略 + 公式 → 结果**直接加入自选股池**（`来源` 标注是哪条策略）
  → 按用户配置的通知方式**发一条消息**（默认 QQ 浮窗；飞书可选）。

**（2）策略编辑器**（点【策略编辑】或点列表里的一条进入）—— **傻瓜式左右布局**，与现在一致但更聚焦：
- 左：公式名称 + 备注 + 编辑框（等宽字体、Tab 插空格、通达信/同花顺风格语法）；
- 右：**变量 + 函数 + 运算符** 点一下插到光标处（共 41 个按钮，已有实测：插在光标处、`MA` 自动带括号、
  `AND` 自动补空格、每个按钮有中文提示）；
- 底部：【校验】→【试算】（本地库最近交易日能选出几只）→【保存】（可另存为）；
- **不再放"成绩单"**：数据只有 6 个月，而成绩单自己有 250 个交易日的样本门槛（`research/scorecard.py:128`），
  放上来只会永远显示"样本不足"。（`--scorecard` 的 CLI 能力保留，不作为界面入口。）

### TAB 5 系统设置
五组，**页面底部一个【保存设置】一键写回全部**（保留 `config.toml` 里用户自己的注释与未知键）：

| 组 | 控件 |
|---|---|
| 数据来源 | **来源列表**（可添加/删除，每条 = 来源 + 它自己的 API Key + 启用开关）：内置同花顺（主来源）排第一；其它**已实现的来源**由用户自己填 Key 添加。下面跟数据量（**下载 6 个月**）、数据目录、日志路径，以及【下载数据】【刷新数据】【检查盘面】【暂停提醒】 |
| 通知方式 | 通知方式：**QQ 浮动消息（默认开）** / 系统弹窗 / 托盘气泡 / 飞书推送（四个勾选框，飞书含凭证三栏）；提示音、托盘图标闪烁、浮窗停留秒数、浮窗条数上限 |
| 竞价扫描 | 开关（默认关）+ 涨幅下限/上限、成交额下限、板块、打分阈值、推送条数、扫描时刻 |
| **T策略** | 总开关（**默认关**）+ 四个做T阈值 + **止盈比例 / 止损比例**（用户给定：这两个比例在 T策略里编辑，默认 −5% / +10%） |
| 其他 | 界面主题（银色/系统默认）；当日异动提醒开关（**默认关**）；自选股上限 |

- 定时运行**整组移除**：不再有"每天自动运行/主跑时间/补跑时间"（用户明确：选股随时手动，不设定时）。
- 策略组/策略的启停**从设置页移到「策略选股」的列表里**（一处只管一件事）。

## 五、数据与存储的兼容

- **持仓"数量"**：界面不再显示、添加表单不再要求；库里 `position.quantity` 保留。
  新加的持仓写入 `quantity = 0`，并把 `load_positions` 的门槛从 `quantity > 0` 改成"未被显式平仓"，
  这样"只记代码+成本+备注"的持仓也能正常出现（老库里的行不受影响）。
- **"现价"口径**：优先用**实时快照**（60 秒轮询，与盘中提醒同一份数据）；
  没有实时数据（收盘后 / 未配 Key）用本地日线最新收盘价，**并在单元格里标注**（`12.34*` + tooltip 说明）。
  绝不用**后复权价**冒充现价（老代码在持仓页混用过后复权价，这次改掉）。
- **自选股上限** `watchlist_max`（20）保留：超出时**明确提示**（不静默丢弃）。

## 八、已定的细节（B1 阶段拍板，避免反复）

1. **名称格式**：所有**给人看**的地方统一半角 `名称(代码)`（表格、推送正文、QQ 浮窗、提醒详情、CLI 打印、
   文档示例）；存储与机器可读格式（CSV/JSON）不动。
2. **窗口标题**只写 `老A选股助手`；版本/版权在【关于软件】与【显示详情】里。
3. **缺 API Key 不再弹模态框**：在「系统设置 → 数据来源」页内提示 + 焦点落到输入框 + 运行状态一句话。
   全应用只剩一处模态确认（删除公式 —— 不可撤销的决定）。
4. **持仓监控的【关闭监控】＝ 这只票不再产生任何盘中提醒**（止损/止盈/做T/竞价/异动），
   且不再进观察池；同一只票若同时是策略标的或自选，**以持仓上的监控开关为准**。
   自选股池的【关闭监控】沿用自选股 `enabled` 的既有语义（不进池、不监控）。
5. **「来源」列**写清"是哪条策略选出来的"：`策略·短期反转` / `公式·放量上攻` / `自选` /
   两者都有时加 `+自选`。组别与持有期、以及"（依赖开盘）"这类证据标记放进行 tooltip
   （列数被规格定死成 6/8 列，不能靠加列塞信息）。
6. **卡片视图与【复制条件单】整套删除**；`pool_view` 配置键保留但界面不再读（是"停止使用"，不是保留语义）。
7. **分数 / 涨停·连板·原因 / 个股竞价行**这些原来在卡片上的信息，进对应行的 tooltip。
8. **选股结果的保留**：「策略选股」页在选股后列出本次命中（`名称(代码)` + 来源），
   并提供【全部加为自选】一键把它们写进 `watchlist`（受 `watchlist_max` 限制，超出明确提示）——
   这样这批票能长期留在自选股池里；不点则只是当日池子行（来源仍标 `策略·xxx`）。
9. **进度条**只在任务运行时出现；标题区不做成常驻进度条。
10. **盘前/无实时快照时**：现价/涨幅用**不复权**的本地最新收盘价并标 `*`（tooltip 写明日期、"不是实时价"）；
    绝不用后复权价与真实成本混算（这是改版修掉的老 bug）。

## 七、用户已拍板的三件事（原未决问题）

1. **数据来源 = 可添加的多个来源，各自用自己的 Key**（用户原话：可用的其它源，让用户自主添加，用他自己的 key）。
   界面是一个来源列表：内置**同花顺**（主来源，实时快照唯一提供方）在上，下面是用户自己添加的来源
   （每条含"来源 / API Key / 启用"）。**只列已实现的来源**，不做假按钮；能力矩阵在界面上写清楚
   （哪个源提供"历史日K / 股票列表 / 实时快照"）。
   第二个已实现的来源：**东方财富公开接口（免 Key）** —— 本机实测可用：
   ① 全市场快照一次拿到 5559 只（代码/名称/现价/涨幅/成交量/成交额/最高/最低/今开/昨收）；
   ② 单只历史日K（前复权）可用。所以"没填同花顺 Key"的用户也能看到两张表的现价/涨幅。
   （如果用户还有 Tushare / 聚宽 之类带 token 的源想接，告我一声再加 —— 那种没有用户自己的 token
   我无法端到端验证，会如实标注"未用真实 token 验证过"。）
2. **不做自动交易，所以"持仓数量"没有意义** —— 界面彻底不要数量（只留 代码 / 成本 / 备注）；
   库里的 `quantity` 列保留仅为兼容老库与历史行（新行写 0，靠"未平仓"判据显示）。
   与之相关的条件单/下单类功能（复制条件单、交易参数）保持移除状态。
3. **止盈/止损比例由用户自己设，位置在「T策略」里**（不再单开一组）：
   默认 −5% / +10%，与四个做T阈值、总开关放在同一组。
