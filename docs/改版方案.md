# 老A选股助手 · 改版方案（按用户给定布局重构）

> 定位：**股票助手**，是行情软件的有效补充 —— 不替代券商客户端，只做"看一眼就知道该干什么"。
> 本文件是改版的**唯一对齐依据**：界面做成什么样、旧功能去哪儿、默认值是多少，以这里为准。
> NAS 服务器版（`/vol4/@apphome/dsh/选股/` 根目录）**一个字节不动**，本次只改 `laoA/`。

---

## 一、标题区（不再是"状态栏 + 一排按钮"）

```
老A选股助手  ·  运行状态：正在下载历史数据 48%（写入行情 62 万行 / 285 万行）   [显示详情] [关于软件]
```

- **软件名称 + 运行状态**在同一行：状态就是"现在在干什么"，下载/刷新/选股/盘中轮询全部显示在这里
  （原来状态、进度条、按钮分散成三行，改成一件事只说一次）。
- **【显示详情】**：点开看完整信息（数据日期、股票数、库大小、下次检查、今日提醒计数、数据目录、日志路径、
  自检阈值）。原来散在状态栏与多处提示里的长期信息都收进这里。
- **【关于软件】**：版本/版权/源码地址/复制版本信息。
- **原则：尽量减少弹窗式提示**。只有"必须让用户做决定"的才弹；
  其余一律写进标题区状态 + 通知消息（通知是否发、发哪些，**全部由用户配置**）。
  **2026-09-17 更新：连"缺 API Key 时输入 Key"那一个也没了** —— 分发版默认走免 Key 的公开行情源，
  界面上不再有 Key 输入框；全应用只剩**一处**模态确认（覆盖/删除公式，不可撤销的决定）。
- 标题区**不再放操作按钮**：数据下载/刷新/选股都在各自的页面里（数据在「系统设置」，选股在「策略选股」）。

## 二、五大页签

### TAB 1 大盘概览（2026-09-17：页签名从「全市概览」改回「大盘概览」）
**四块**，竖直排列，窄窗口自动换列；**所有「名称」加粗、数值不加粗**：

| 块 | 内容 |
|---|---|
| **成交与情绪**（最上面，2026-09-17 新增） | `成交额`（**沪 + 深 相加一个数**）+ 涨停 / 跌停 / 炸板 / 上涨 / 下跌 / 平盘 —— **7 个小条目排成一行**（宽屏一行 7 个，窄屏自动换行）。**北交所成交额已删除**。**一条一个数**而不是合成一句话：合成文本在 Windows 字体下会被自己的列宽截掉（CI 实测过），拆开之后任何字体都塞得下 |
| 宽基指数 | **7 只**：上证 / 深成 / 创业板 / 科创50 / 沪深300 + **上证50（`000016.SH`）** + **中证1000（`000852.SH`）** —— 点位 + 涨跌幅（各自按涨跌上色）。实现 = 配置默认 5 只（`config.DEFAULT_MARKET_INDICES`）+ 取数层补 2 只（`market.WIDE_INDEX_EXTRA_CODES`） |
| 情绪指数 | 同花顺情绪类板块指数 —— **只剩指数条目**（小条目都搬到上面那一块了） |
| 热门板块 | **上涨前五 + 下跌前五 两张表**，表头四个词固定为 `板块名称 / 涨停数量 / 涨幅 / 主力净额`（各带 tooltip 写口径）。排序 = 涨幅降序取前 5 / 升序取前 5。数据来自腾讯行业板块排行（免 Key），`主力净额` 来自它的 `zljlr`（**原始单位万元** → 界面按**亿**显示）；取不到时退回**本地口径**（涨幅 = 近 5 日行业等权涨幅，**页内写明"不是当日涨幅"**，主力净额 `—`） |

页脚一行：`数据来源：公开行情接口（腾讯/新浪/东财）与同花顺金融数据服务；非交易所授权行情 · 更新于 HH:MM（每分钟自动刷新；涨跌家数每 5 分钟更新）` + 【立即刷新】。

### TAB 2 自选股池
- **添加入口**：代码 + 备注 →【添加自选】（回车即加）。
- **表格列**（**8 列**）：`名称(代码) | 现价 | 涨幅 | 市值 | 换手 | 板块 | 来源 | 监控开关`
  - **现价 / 涨幅**：实时快照（60 秒轮询）优先；没有实时数据时用本地最新收盘价，
    **单元格里不加任何符号**（`*` 已彻底去掉），区别写在 tooltip 里（"这是本地最新收盘价（MM-DD），不是实时价"）；
  - **市值** = **流通市值（亿）**、**换手** = **实时换手率（%）**：都来自实时快照，
    **取不到显示 `—`（不是 0）**——0 亿市值 / 0% 换手是真实存在的值；
  - **板块**：`stock_basic.industry`；
  - **来源**：`策略·<策略名>` / `公式·<公式名>` / `自选` / `策略+自选`（沿用现有 `pool.source_label`）；
  - **监控开关**（2026-09-17 由原来的「提醒」列改名）：文字是 `开启` / `关闭`，
    **点一下这一格就能切换**（与右键【关闭监控】/【打开监控】同一个动作）；
    **今日最新一条提醒的完整内容挪进了这一格的 tooltip**（内容没丢）。
- **交互**（三张表统一）：
  - 悬浮 → 显示备注（有备注的行）；
  - 右键菜单 → 【删除】/【关闭监控】↔【打开监控】；
  - **单击 → 打开雪球个股页**（`https://xueqiu.com/S/SH600000` 这种，复用 `notify/windows.py:to_xueqiu_code()`）。
- 本表**同时**显示策略/公式选出来的票（`来源` 列区分）与手工添加的自选股 —— 这是"池子"的唯一入口。
- 表头右侧一行小字：`共 N 只（策略 M · 自选 K）`。

### TAB 3 持仓监控
- **添加入口**：代码 + 成本价 + 备注 →【添加持仓】；同一行右侧一个复选框 **T策略**（默认关，与「系统设置」里的是同一个开关）。
- **表格列**（**10 列**）：`名称(代码) | 成本价 | 现价 | 涨幅 | 市值 | 换手 | 盈亏比例 | 止损位 | 止盈位 | 监控开关`
  - 盈亏比例 = `(现价 − 成本) / 成本`，涨红跌绿，缺价显示 `—`（不显示 `0.00%`）；
  - 市值/换手 = 与自选股池**同一套口径**（流通市值亿 / 实时换手率%，取不到 `—`）；
  - 止损位/止盈位 = `成本 × (1 ∓ 止损/止盈比例)`，比例在「系统设置 → T策略」里改；
  - 监控开关与自选股池同一口径（`开启`/`关闭` + 点一格切换 + tooltip 里带今日最新一条提醒）。
- 交互同上（悬浮备注 / 右键删除与开关监控 / 单击开雪球）。
- **数量不再出现在界面上**：持仓只记"代码 + 成本 + 备注"（用户给定的字段），
  原来的"数量"字段保留在库里做兼容（详见第五节）。

### TAB 4 策略选股
上下两块：

**（1）策略列表** —— 内置策略与自定义公式**同一张表**：`名称 | 备注 | 状态`
- 内置 5 条固定在内（备注列写明它的证据，例：`两套口径都为正 · B +0.03%(t=1.38)`、
  `⚠️ 只在"开盘买"口径为正`、`⛔ 默认关闭：两套口径显著为负`）；
- 自定义公式追加在后（备注来自公式文件的 `# 说明:`）；
- **单击一行 → 打开编辑**（内置策略只读展示条件说明；公式可改可另存）；
- **右键菜单** → 【启用】↔【关闭】/【删除】（内置策略不可删，只能启停）；公式的启停写回 `enabled_formulas`；
- 【开始选股】：跑所有**启用**的策略 + 公式 → 结果**直接加入自选股池**（`来源` 标注是哪条策略）
  → **同时往桌面导出一个文本文件** → 按用户配置的通知方式**发一条消息**（默认 QQ 浮窗；飞书可选）。
- **本页不再有「选股结果」区**（2026-09-17 用户要求）：旧版那块「本次选股结果」表 + 一句话结论 +
  【全部加为自选】按钮**已删除**；结果的两个去处就是「自选股池」页与桌面文件，页面上那行灰字说明写清了这两件事。
- **桌面导出**（`pool.export_pick_file()`，在建池成功后调用，三条路都有文件）：
  文件名 `老A选股助手-选股结果-YYYY-MM-DD.txt`（日期 = 导出当天），**UTF-8 带 BOM + CRLF**，
  正文 = 标题（含行情日）+ `共 N 只（策略 M · 自选 K）` + 每行 `序号. 名称(代码)  现价 x  来源：…` + 免责声明一行；
  桌面目录解析顺序 = 系统答案（Qt，认 OneDrive 重定向与中文"桌面"）→ `Desktop` → `桌面` →
  OneDrive 下两者 → 都没有就**回退数据目录**；导出失败**只记日志**，不影响选股/建池/推送；
  **同一天再跑会覆盖同名文件**。

**（2）策略编辑器**（点【策略编辑】或点列表里的一条进入）—— **傻瓜式左右布局**，与现在一致但更聚焦：
- 左：公式名称 + 备注 + 编辑框（等宽字体、Tab 插空格、通达信/同花顺风格语法）；
- 右：**变量 + 函数 + 运算符** 点一下插到光标处（共 41 个按钮，已有实测：插在光标处、`MA` 自动带括号、
  `AND` 自动补空格、每个按钮有中文提示）；
- 底部：【校验】→【试算】（本地库最近交易日能选出几只）→【保存】（可另存为）；
- **不再放"成绩单"**：数据只有 6 个月，而成绩单自己有 250 个交易日的样本门槛（`research/scorecard.py:128`），
  放上来只会永远显示"样本不足"。（`--scorecard` 的 CLI 能力保留，不作为界面入口。）

### TAB 5 系统设置
五组，**页面底部一个【保存设置】一键写回全部**（保留 `config.toml` 里用户自己的注释与未知键）：

| 组 | 控件 |
|---|---|
| 数据来源 | **来源列表**（可添加/删除，每条 = 来源 + 标记 + 能力 + 风险说明 + 启用开关）：**免 Key 的公开行情源排第一、标「主来源」（腾讯为主 + 新浪兜底）**，**内置同花顺标「备用源」**且**不再有 Key 输入框、也没有【测试连接】**（只剩一行说明 + 可点开的申请地址 `https://fuyao.aicubes.cn`；手改 `config.toml` 或设 `HITHINK_FINANCE_API_KEY` 照旧有效）；其它**已实现的来源**由用户自己添加。下面跟数据量（**下载 6 个月**）、数据目录、日志路径，以及【下载数据】【刷新数据】【检查盘面】【暂停提醒】 |
| 通知方式 | 通知方式：**QQ 浮动消息（默认开）** / 系统弹窗 / 托盘气泡 / 飞书推送（四个勾选框，飞书含凭证三栏）；提示音、托盘图标闪烁、浮窗停留秒数、浮窗条数上限 |
| 竞价扫描 | 开关（默认关）+ 涨幅下限/上限、成交额下限、板块、打分阈值、推送条数、扫描时刻 |
| **T策略** | 总开关（**默认关**）+ 四个做T阈值 + **止盈比例 / 止损比例**（用户给定：这两个比例在 T策略里编辑，默认 −5% / +10%） |
| 其他 | 界面主题（银色/系统默认）；当日异动提醒开关（**默认关**）；自选股上限 |

- 定时运行**整组移除**：不再有"每天自动运行/主跑时间/补跑时间"（用户明确：选股随时手动，不设定时）。
- 策略组/策略的启停**从设置页移到「策略选股」的列表里**（一处只管一件事）。

## 五、数据与存储的兼容

- **持仓"数量"**：界面不再显示、添加表单不再要求；库里 `position.quantity` 保留。
  新加的持仓写入 `quantity = 0`，并把 `load_positions` 的门槛从 `quantity > 0` 改成"未被显式平仓"，
  这样"只记代码+成本+备注"的持仓也能正常出现（老库里的行不受影响）。
- **"现价"口径**：优先用**实时快照**（60 秒轮询，与盘中提醒同一份数据）；
  没有实时数据（收盘后 / 没配 Key）用本地日线最新收盘价 —— **2026-09-17 起单元格里不加任何符号**
  （原来的 `12.34*` 被用户误读成"监控状态标记"），改由 **tooltip** 写明"这是本地最新收盘价（MM-DD），
  不是实时价"。绝不用**后复权价**冒充现价（老代码在持仓页混用过后复权价，这次改掉）。
- **"市值 / 换手"口径**：都取**实时快照**里的 `circ_mktcap`（流通市值，亿）与 `turnover_rate`（%）；
  快照只在交易时段取、且来源得提供这两个字段，**取不到一律 `—`**（绝不拿 0 冒充"没取到"）。
- **自选股上限** `watchlist_max`（20）保留：超出时**明确提示**（不静默丢弃）。

## 八、已定的细节（B1 阶段拍板，避免反复）

1. **名称格式**：所有**给人看**的地方统一半角 `名称(代码)`（表格、推送正文、QQ 浮窗、提醒详情、CLI 打印、
   文档示例）；存储与机器可读格式（CSV/JSON）不动。
2. **窗口标题**只写 `老A选股助手`；版本/版权在【关于软件】与【显示详情】里。
