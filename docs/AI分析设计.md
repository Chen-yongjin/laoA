# AI 分析（决策信号）设计稿

这份文件只记**已经定下来的事**和**还没定的事**，代码写完后按实际实现回填。
当前状态：**骨架已落地**（`src/laoa_trader/analysis.py` + `tests/test_analysis.py`），
界面、网络信息抓取、回测标定三块还没做。

## 0. 分工（用户 2026-10-13 定）

> 「程序搭好架子，大模型只是辅助作用，可以从网上收集一些不是行情数据能读到的信息。」

三层，边界不许串：

1. **数据层（程序）**：行情、资金、公告原文、账户事实 —— 已有的那些接口照旧。
2. **判据与结论层（程序，骨架）**：因子 → 规则 → 进场信号 / 离场信号。
   跑一遍不联网、不花钱、结果可复现；**同一份数据同一版判据，结论必须一模一样**。
3. **辅助层（大模型，可关）**：把程序抓到的公告/新闻/行业消息读完，挑出跟这只票相关的，
   写成几句附注挂在结论下面。**它不改结论、不定阈值**；没配 Key、断网、调用失败 ⇒
   结论照出，只是少那几行附注（界面上写明"消息未获取，不影响结论"）。

## 1. 定位与合规边界

- 这是**信号系统**，不是荐股工具。对外一律用**进场信号 / 离场信号**的说法，
  不用「建议买入」「建议卖出」这类指令式措辞（主人 2026-10-13 定：措辞要严谨）。
- **只描述条件成不成立**，每条结论都要能追到一条可读的公式、一个字段或一个网址。
- 分析结果页底部固定一行免责声明（本工具只做数据与形态的描述性统计，不构成投资建议）。

## 2. 触发方式

- **只在用户手动点「分析」时执行**，不自动跑、不定时跑、不开机跑（主人明确要求）。
- 分析对象：单只标的（详情窗/右键）与批量（自选池、持仓各一次「全部分析」）。
- 分析不写回行情、不改池子成员，只产出结论 + 依据 + 历史统计；结论落库供回看。

## 3. 结论集（按对象分流）

自选池里的标的**默认就是观望状态**，分析要回答的是「还值不值得继续放在池子里观察」：

- 自选池 → 进场信号成立 / 继续观察（无信号） / 建议剔除（偏弱且长期无进场条件）
- 持仓 → 持有 / 减仓 / 离场信号成立

「建议剔除」只是把标的从**自选池**里移出的建议，不是清仓建议，两者互不替代。

## 4. 判据从哪来

- **阈值由回测标定，程序执行，模型只解释。** 先跑数据得出「哪几条规则、在什么阈值下、
  多少样本、胜率与超额是多少」，达标的那几条固化成判据；大模型不参与定阈值。
- 阈值收在一个 `RuleSet` 里（带 `version` 与 `calibrated`）。现在 `calibrated=False`，
  结论里会照实写「阈值尚未回测标定」—— 不许把拍脑袋的默认值当回测结论。
- 持仓的「减仓 / 离场」同样由回测制定；**用户自己设的止损止盈一旦触发就是离场信号**，
  程序不推翻用户定的线（只在他没设线时按评分 + 资金给判断）。

## 5. 输入因子（回测与解释共用同一套）

技术面：MA/EMA、MACD、RSI、KDJ、CCI、WR、BOLL、OBV、量比、ADX/±DI、ATR、MFI、
20 日极值、形态（含涨停连板、二板炸板）、相对强弱 RS；快照类（现价/涨幅/量比/换手/流通市值）。
资金面：主力净额、净占比、近 5 日主力净额、行业级资金、竞价三项（9:15-9:30，需同花顺 Key）。
大盘情绪：成交额、涨跌家数、涨停跌停炸板、宽基与情绪指数、热力图、热门行业。
账户面：成本、盈亏、止损止盈设置、提醒历史、策略来源与那条策略的成绩单。
评分：现有 5 维 17 项。
基本面：估值（PE/PB/PS/PCF）**待接入**，接之前不参与结论。

## 6. 网络信息（行情数据读不到的那部分）

这一块**归大模型那条线，但是抓取仍由程序做**（要能复现、能给出网址、能缓存）：

- 抓什么：公司公告（东财公告接口，无 Key）、个股新闻、行业/政策消息。
- 怎么用：程序把**原文**（标题 + 时间 + 网址，必要时正文）拉回来，大模型只做
  「跟这只票有没有关系、好事还是坏事、一句话说完」。挑不出相关的就一条都不给。
- 规矩：附注**只增不改**结论；每条都要带日期与网址；同一只票同一天的结果缓存，
  不重复调用；界面上明确标"由大模型归纳，仅供参考"。

## 7. 前置任务（不做完出不了可靠结论）

1. **历史数据补到 2~3 年**：现在库里只有约 10 个交易日（约 5.56 万行 / 5560 只），
   回测样本太少；快照类与竞价类字段**没有历史**，回测只能跑日线类与资金类因子。
2. **因子体检表**：每个因子单独出样本数、胜率、T+3/T+5/T+10 超额、最大回撤，
   先在报告里看一遍，不合格的因子不进判据。
3. 判据固化：体检通过的规则组写成 `RuleSet`，带版本号，替换掉现在的临时阈值。

## 8. 回测口径（沿用策略成绩单已有的口径）

- A 股 T+1：D 收盘匹配 → D+1 进场 → 按持有期（T+3/T+5/T+10）收盘出场，
  出场日必须严格晚于进场日，T+0 一律拒绝。
- 卖出侧不剔除（跌停卖不出去是真实风险，报告里单列提示）。
- 报告拆强市/弱市、拆行业，避免结论只在大盘单边行情里成立。

## 9. 还没定的事

- 自选池要不要分档（强/中/弱三档 vs 只给「够不够格继续观察」二元）；
- 「减仓」与「离场」的分界（现在用的是评分 45 / 30 两档 + 资金净流出）；
- 基本面估值接哪一路（同花顺 `valuations()` 需 Key，或东财 `f9/f23`，后者还没接线）；
- 大模型那条线接哪一家（用户自带 Key 走 OpenAI 兼容接口，还是别的方案）、
  新闻/公告抓取源选哪几家。
