# AI 分析（决策信号）设计稿

这份文件只记**已经定下来的事**和**还没定的事**，代码写完后按实际实现回填。
当前状态：**设计阶段，未开始编码**。

## 1. 定位与合规边界

- 这是**信号系统**，不是荐股工具。对外一律用**进场信号 / 离场信号**的说法，
  不用「建议买入」「建议卖出」这类指令式措辞（主人 2026-10-13 定：措辞要严谨）。
- **只描述条件成不成立**，结论里写清「依据的是哪几条已在策略库里生效的规则」，
  用户自己决定做不做。软件里出现的任何结论都要能追到一条可读的公式或一段可核的数据。
- 分析结果页底部固定一行免责声明（本工具只做数据与形态的描述性统计，不构成投资建议）。

## 2. 触发方式

- **只在用户手动点「分析」时执行**，不自动跑、不定时跑、不开机跑（主人明确要求）。
- 分析对象：单只标的（详情窗/右键）与批量（自选池、持仓各一次「全部分析」）。
- 分析不写回行情、不改池子成员，只产出结论 + 依据 + 历史统计；结论落库供回看。

## 3. 结论集（按对象分流）

自选池里的标的**默认就是观望状态**，分析要回答的是「还值不值得继续放在池子里观察」：

- 自选池 → 进场信号成立 / 继续观察（无信号） / 建议剔除（离场信号成立且长期无进场条件）
- 持仓 → 持有 / 减仓 / 离场信号成立

「建议剔除」只把标的从**自选池**里移出的建议，不是清仓建议，两者互不替代。

## 4. 判据从哪来（关键决定）

- **阈值由回测标定，模型只负责解释。** 先跑数据得出「哪几条规则、在什么阈值下、
  多少样本、胜率与超额是多少」，把达标的那几条固化成判据；大模型不参与定阈值。
- 大模型只做三件事：把多条判据归纳成一段人话、指出判据之间的冲突、把用户自己的
  成本/提醒历史/策略来源一起纳入解释。**没有大模型也必须能出结论**（降级为纯规则结论）。
- 持仓的「减仓 / 离场」判据同样由回测制定：以该标的进场日之后的走势统计为准，
  不用固定百分比拍脑袋。

## 5. 输入因子（回测与解释共用同一套）

技术面：MA/EMA、MACD、RSI、KDJ、CCI、WR、BOLL、OBV、量比、ADX/±DI、ATR、MFI、
20 日极值、形态（含涨停连板、二板炸板）、相对强弱 RS；快照类（现价/涨幅/量比/换手/流通市值）。
资金面：主力净额、净占比、近 5 日主力净额、行业级资金、竞价三项（9:15-9:30，需同花顺 Key）。
大盘情绪：成交额、涨跌家数、涨停跌停炸板、宽基与情绪指数、热力图、热门行业。
账户面：成本、盈亏、止损止盈设置、提醒历史、策略来源与那条策略的成绩单。
评分：现有 5 维 17 项。
基本面：估值（PE/PB/PS/PCF）**待接入**，接之前不参与结论。

## 6. 前置任务（不做完出不了可靠结论）

1. **历史数据补到 2~3 年**：现在库里只有约 10 个交易日（约 5.56 万行 / 5560 只），
   回测样本太少，且快照类与竞价类字段**没有历史**，回测只能跑日线类与资金类因子。
2. **因子体检表**：每个因子单独出样本数、胜率、T+3/T+5/T+10 超额、最大回撤，
   先在 report 里看一遍，不合格的因子不进判据。
3. 判据固化：体检通过的规则组写入判据集，带版本号（与 `scoring.MODEL_VERSION` 同样的做法）。

## 7. 回测口径（沿用策略成绩单已有的口径）

- A 股 T+1：D 收盘匹配 → D+1 进场 → 按持有期（T+3/T+5/T+10）收盘出场，
  出场日必须严格晚于进场日，T+0 一律拒绝。
- 卖出侧不剔除（跌停卖不出去是真实风险，报告里单列提示）。
- 报告拆强市/弱市、拆行业，避免结论只在大盘单边行情里成立。

## 8. 还没定的事

- 「减仓」与「离场」的分界判据（是否用回撤 + 资金流出组合）；
- 基本面估值接哪一路（同花顺 `valuations()` 需 Key，或东财 `f9/f23`，后者还没接线）。
