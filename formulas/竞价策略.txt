# 名称: 竞价策略
# 说明: 集合竞价择强 · 适合在 9:25-9:30 之间运行

ZC:=现涨幅          # 竞价/开盘涨幅（百分数：3.2 就是 +3.2%）
LB:=现量比          # 量比（倍）
PME:=竞价匹配额     # 9:15–9:25 集合竞价撮合金额，单位万元（不是全天成交额）

# 【什么时候跑】适合在 9:25-9:30 之间运行：9:25 竞价撮合结束（量额已定、当天第一份真实
#   买卖盘），9:30 才开盘 —— 这时跑看到的是"抢筹结果"。点【运行】只看能选出几只；
#   点【开始筛选】把命中的票进池（同时进「自选标的」+ 导出一份到桌面）。
# 【竞价匹配额是什么】= 集合竞价撮合出来的金额（万元），就是通达信竞价图里的"匹配额"。
#   它只是竞价那一段，不等于全天成交额、也不等于昨天的成交额；写 >=1000 就是
#   "竞价撮合了 1000 万元以上"。引擎已经替你把接口的"元"换算成"万元"（÷1e4）。
# 【每一条判据】见下面四行（都标着"改这里就行"）。另外这几个字段也有值，想加就接一段：
#   `竞价匹配量`（手）、`竞价未匹配量`（手，正=买盘剩余、负=卖盘剩余）、
#   `现换手`（%；9:25 的竞价换手通常只有零点几个百分点，先试 0.2）、`流通市值`（亿元）。
#   例：AND 竞价未匹配量>0
# 【两条硬限制】1) 现涨幅 / 现量比 / 竞价匹配额 取不到时一律不成立 → 一只都不出
#   （那是"没有数据"，不是"今天没有强势股"）；2) 它们只有"当下"一个值、没有历史
#   → 无法回测，【成绩单】里没有成绩。
# 【依赖】竞价数据只有同花顺接口给（要在「系统设置 → 数据来源」里配 Key，或设环境
#   变量 HITHINK_FINANCE_API_KEY），而且只有 9:15–9:30 取得到 —— 没配 Key 或不在
#   这个时段跑，这条策略一只都不出（结果页会说明是哪一种原因，照那句指路做即可）。
GAIN_OK:=ZC>=2 AND ZC<9       # 改这里就行：涨幅 2%~9%（低开不看；≥9% 多是一字板买不进）
LB_OK:=LB>=2                  # 改这里就行：放量 ≥2 倍（写 3 更严、1.5 更松）
PME_OK:=PME>=1000             # 改这里就行：竞价匹配额 ≥1000 万（写 2000 更严、500 更松）
BOARD_OK:=ST=0                # 改这里就行：排除 ST；只留主板+创业板接 AND 科创=0 AND 北交所=0
GAIN_OK AND LB_OK AND PME_OK AND BOARD_OK
