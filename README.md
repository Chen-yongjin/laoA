# 财神助手（Windows 单机版）

**它是行情软件的辅助工具，不是行情软件，也不下单。** 行情照旧看同花顺 / 通达信；
它负责回答"看哪些票、什么时候该动手"。

两个主打特色：

1. **最简单的策略编辑** —— 通达信 / 同花顺的公式粘进来就能跑；右边一排中文按钮，点一下就插到光标处，不用记语法。
2. **盘中监控** —— 交易时段按分钟盯池子与持仓，触及止损 / 止盈 / 涨停打开等情况立刻提醒（图标闪烁 + 「消息」列表，飞书 / 语音 / 桌宠可另开）。

当前版本 **1.3.0**。版本号只有一个真源：`src/laoa_trader/__init__.py` 的 `__version__`。

产品名分三层：界面与窗口标题是「财神助手」，通知 / 导出文件名自称「财神助手」，
exe 叫 `财神助手.exe`，而目录与压缩包用 ASCII 的 `CaishenTrader`。

## 一、功能一览

界面是一个标题区 + 五个页签。

### 页签 1 · 大盘概览（启动默认停在这一页）

- 四块，竖直排列：**成交与情绪 → 宽基指数 → 情绪指数 → 热门板块**。
- 成交与情绪：沪深成交额（一个数）+ 涨停 / 跌停 / 炸板 + 上涨 / 下跌 / 平盘。
- 宽基指数默认 5 只：上证指数、深证成指、创业板指、科创 50、沪深 300。
- 情绪指数默认 4 只：同花顺情绪、昨日连板、昨日打首板表现、微盘股（同一端点，换代码就换一套心情指标）。
- 热门板块：上涨前五 + 下跌前五两张表（板块名 / 涨停数 / 涨幅 / 主力净额）。
- 取数有 55 秒 TTL，不跟着界面的 5 秒定时器打接口。某一路失败只记一条原因，其余照常显示。

### 页签 2 · 自选标的

- **策略选出来的 + 手工加的，同一张表**，靠「来源」列区分。
- 10 列：名称(代码) / 现价 / 涨幅 / 市值 / 换手 / 板块 / 来源 / 加入日期 / 盈亏 / 监控开关。
- 表头右侧一行小字：`共 N 只（策略 M · 自选 K）`，三个数互斥（M + K = N）。
- 现价优先用实时快照；取不到时用本地**不复权**收盘价并标 `*`。
- 「监控开关」点一下就切换：关闭的票不产生任何盘中提醒，但留在池子里。
- 右键可加为自选、删除；自选上限 `watchlist_max`（默认 20），超限会明确提示而不是静默丢弃。

### 页签 3 · 持仓监控

- 记「代码 + 成本价 + 备注」三样，填完点【添加持仓】。
- 10 列：名称(代码) / 成本价 / 现价 / 涨幅 / 市值 / 换手 / 盈亏比例 / 止损位 / 止盈位 / 监控开关。
- 盈亏比例 =（现价 − 成本价）÷ 成本价；止损位 / 止盈位按成本价与 `stop_loss` / `take_profit` 算。
- 取不到价显示 `—`，不写 0.00%（那会被读成"刚好打平"）。
- **持仓票自动进入盘中提醒的观察面**：止损/止盈按**成本价**算，跌破 5 日线 / 涨停打开按本地历史；不必再手动加进自选。做T提示仍由下面的开关单独控制。
- 同一行右侧有 **T策略开关**，与「系统设置 → T策略」是同一个配置键（`intraday_t`）。

### 页签 4 · 策略匹配

- 上半是策略列表，三列：`策略名称 | 说明 | 策略选取`（勾上才参与匹配）。
- 列表最上面一行是「竞价策略」——唯一不是匹配策略的行，勾它开关的是盘中竞价扫描。
- 上半右键：启用 / 关闭 / 删除（公式可删，「竞价策略」那一行不可删）。单击公式行即载入编辑器。
- 下半是编辑器：左边写、右边点按钮插入（变量 / 函数 / 运算符 / 排除），全中文按钮。
- 底部按钮：校验 / 运行 / 导出匹配结果 / 保存 / 另存为 / 删除。【运行】只跑一遍看能选出几只，不推送、不写库。
- 右上角【开始匹配】跑完整流程：增量数据 → 跑勾选的策略 → 建池 → 推送 → 往桌面写一份匹配结果文件。

### 页签 5 · 系统设置

- 五组：**数据来源 / 通知方式 / 竞价扫描 / T策略 / 其他**，页面底部**一个**【保存设置】一次写回。
- 数据来源：主源是同花顺（要 Key，在那行填），免 Key 的公开源是兜底；列表顺序就是取数优先级。
- 【下载数据】/【刷新数据】/【检查盘面】都在这一组。
- 通知方式：勾飞书 / 托盘气泡，另有自绘浮窗、提示音、图标闪烁、桌宠、中文语音朗读。
- T策略：做T开关 + 四个阈值 + 止损 / 止盈比例（默认关）。
- 其他：界面主题、当日异动提醒、自选标的上限、自选是否进池。
- 自动运行时间、池子默认视图、概览开关与 TTL 这些只在 `config.toml` 里改（界面没有入口）。

### 提醒这一路（不占页签）

- 默认形态是 QQ 那种：**托盘 / 任务栏图标闪 + 点开「消息」列表**，消息自己蹦出来的浮窗默认关着。
- 「消息」列表：时间 / 标的 / 类型 / 说明，未读加粗带圆点，点一条看详情（含可抄进券商的条件单参数）。
- 桌宠默认开：一张常驻桌面、置顶的小卡片，有消息冒气泡 + 蹦两下，双击开消息列表。
- 中文语音朗读默认开，走 Windows 自带语音合成，不引新依赖；机器上没有中文音色就自动不念。
- 飞书 / 托盘气泡两路**默认都不发**（`notify_channels` 默认空），要发自己去勾。
- **盯谁**：股票池 + 自选 + 持仓（持仓票不必再手动加自选）。交易时段每 60 秒一拍，同标的同类型当天只提醒一次。
- **怎么知道它在跑**：状态栏那一句会写成"盘中提醒时段中（10:31 盯 12 只，命中 0 条）"；点【检查盘面】会明确回一句结论 —— 是"没有触发条件的票"，还是"今天不是交易日 / 不在交易时段 / 没配 API Key"。

## 二、快速开始（开发者视角）

### 1. 环境

- **Python 3.11 或更新**（`pyproject.toml` 的 `requires-python = ">=3.11"`）。
- 运行依赖：`requests`、`pandas`、`pyarrow`、`PySide6`，Windows 上还有 `winotify`。
- 开发依赖（`.[dev]`）：`pytest`、`nuitka`（默认构建器）、`pyinstaller`（备用构建器）。

```bash
python -m venv .venv
.venv/Scripts/pip install -e ".[dev]"      # Windows
.venv/bin/pip install -e ".[dev]"          # Linux / macOS
```

> ⚠️ 必须装 `.[dev]`（不是 `-e .`）：只装运行依赖会少 Nuitka，构建时报 `No module named nuitka`。

### 2. 跑测试（必须离屏）

```bash
QT_QPA_PLATFORM=offscreen /tmp/laoa-verify/bin/python -m pytest -q
```

- `QT_QPA_PLATFORM=offscreen` 不能省：界面用例要在没有显示器的环境里建窗口。
- Windows 上：`.venv\Scripts\python -m pytest tests -q`。
- 包装脚本 `run-tests.sh` 等价于上面那条（用 `PY=<python> ./run-tests.sh` 指定解释器）。
- `pyproject.toml` 已把 `testpaths` 指到 `tests`、`pythonpath` 指到 `src`，所以不用先装包也能 import。
- 全量 1800+ 条，本机跑完约 15 分钟；改哪块就先跑哪个文件，别每次等全量。

### 3. 跑程序

```bash
python -m laoa_trader                      # 图形界面（Python 3.11+）
python -m laoa_trader --cli --doctor       # 自检：路径 / 依赖 / 凭据 / 数据概况（排障先跑它）
python -m laoa_trader --cli --once         # 跑一次：数据增量 + 匹配 + 建池
python -m laoa_trader --cli --pool         # 只看当前股票池
python -m laoa_trader --cli --market       # 只看大盘概览那几行
python -m laoa_trader --cli --download     # 下载 / 更新历史数据（可中断，重跑续传）
python -m laoa_trader --cli --serve        # 常驻：定时日更 + 盘中提醒
python -m laoa_trader --cli --version      # 版本 + 构建形态（报障先跑这个）
```

Windows 上双击 `一键运行.bat` 最省事：建 `.venv` → 装依赖 → 起界面。

其余命令行参数：

| 参数 | 作用 |
|---|---|
| `--config <路径>` | 指定 config.toml |
| `--watchlist add 600519 --note 龙头` | 自选标的管理：`add` / `list` / `remove` / `enable` / `disable` |
| `--no-notify` | 只落库，不推送 |
| `--auto-download` | 自检发现数据不可用时先自动下载再继续 |
| `--force-download` | 配合 `--download`：数据已就绪也强制重下 |
| `--run-at 16:30` / `--run-at-fallback 19:15` | 临时覆盖运行时间（只改内存，不写配置文件） |
| `--no-auto-run` | 临时关掉「每天自动运行」 |
| `--interval 60` / `--limit 200` | 盘中轮询间隔（秒） / 只处理前 N 只（试跑） |
| `--doctor` | 自检报告，并往 `<数据目录>/logs/自检报告.txt` 落一份 |

界面不可用（没装 PySide6）时自动降级为命令行，不会直接崩。

### 4. 打包

**默认 Nuitka**（编译成原生 exe，源码不能被解包还原）：

```bash
python build/nuitka_build.py                          # 直接调构建脚本
build\build.bat                                       # Windows 一键：建 venv + 装依赖 + 构建
```

**PyInstaller 是备用路径**（Nuitka 出问题时退回；源码可被解包还原）：

```bash
.venv\Scripts\pyinstaller --noconfirm --clean build/laoa_trader.spec
```

CI 也走同一套：`.github/workflows/build-windows.yml` 先跑测试，再按 `builder` 输入选 Nuitka 或
PyInstaller，构建完会真的跑一次 `--doctor` 冒烟检查，产物发到 Release。

> 细节（Python 安装、Nuitka 首次 20~60 分钟、产物目录结构、常见报错、注册机）见 `docs/打包教程.md`。
> 两个构建器都不能跨平台：exe 只能在真正的 Windows 上打。

## 四、配置说明

### 文件位置

| 用途 | 位置 |
|---|---|
| 配置文件 | `%APPDATA%\CaishenHelper\config.toml`（非 Windows：`~/.config/caishen-helper/config.toml`） |
| 数据目录 | `%LOCALAPPDATA%\CaishenHelper\data`（数据库 `trader.db`、dump 缓存 `dumps/`、日志 `logs/`） |
| 策略目录 | 打包后是 exe 同级的 `formulas/`；源码运行是仓库根的 `formulas/` |

配置文件查找顺序（第一个存在的生效）：

1. 环境变量 `LAOA_TRADER_CONFIG` 指定的路径；
2. **用户目录**（上表第一行）—— 保存设置永远写这里；
3. 当前工作目录的 `./config.toml`；
4. exe 同级 / 仓库根（老位置）。

> **老位置自动迁移**：用户位置还没有配置、而老位置（exe 同级或工作目录）有，启动时**复制**一份过去。
> 只复制、**不删原文件**（新位置万一写不进去，用户还能手改老那份）；只做一次，失败只记日志、绝不打断启动。
> 为什么必须搬出安装目录：更新软件是整包覆盖 exe 那一层，配置留在那儿会跟着一起没。

### 关键键

字段名以 `src/laoa_trader/config.py` 的 `Config` 为准（`config.example.toml` 是同一份的注释版）。

**数据源**

| 键 | 默认 | 说明 |
|---|---|---|
| `hithink_api_key` | `""` | 同花顺 Key（在 fuyao.aicubes.cn 申请）；没配时匹配会被数据自检拒绝 |
| `data_sources` | `["hithink", "public"]` | 列表即启停、**顺序即优先级**；`public` 免 Key 只当兜底 |
| `data_dir` | `%LOCALAPPDATA%\CaishenHelper\data` | 数据库 / dump / 日志放这儿 |
| `history_years` | `0.5` | 首次导入多少年历史（dump 固定 10 年，导入时按这个值过滤） |
| `min_history_years` | `0.4` | 跨度下限，**必须小于** `history_years`，否则永远判"数据不足" |
| `auto_download_on_start` | `true` | 只对增量自动下载；全量下载始终要用户明确同意 |

**策略与自选**

| 键 | 默认 | 说明 |
|---|---|---|
| `enabled_formulas` | `[]` | 参与匹配的**策略名**（不是路径）；**空 = 只盯自选标的** |
| `watchlist_max` | `20` | 自选数量上限，超限只提示、不静默丢弃 |
| `watchlist_in_pool` | `true` | 自选是否并入池子参与盘中监控 |

**通知**

| 键 | 默认 | 说明 |
|---|---|---|
| `notify_channels` | `[]` | 实际发送的频道（`feishu` / `tray`）；空 = 都不发 |
| `notify_feishu` / `notify_tray` | `true` | 单频道开关，与上面同时生效 |
| `feishu_app_id` / `feishu_app_secret` / `feishu_chat_id` | `""` | 飞书自建应用凭证；缺任一就跳过这一路 |
| `notify_popup` / `notify_popup_seconds` / `notify_popup_max_items` | `false` / `8` / `5` | 右下角自绘浮窗（默认关） |
| `notify_sound` / `notify_flash_seconds` | `true` / `6` | 提示音；图标闪烁秒数（0 = 不闪） |
| `notify_pet` / `pet_x` / `pet_y` | `true` / `0` / `0` | 桌宠开关与位置（0 = 还没拖过，用屏幕右下角） |
| `notify_voice` / `notify_voice_volume` / `notify_voice_name` | `true` / `0.9` / `""` | 语音朗读、音量、音色（`""` 自动 / `female` / `male`） |

**盘中**

| 键 | 默认 | 说明 |
|---|---|---|
| `intraday_interval` | `60` | 交易时段内的轮询间隔（秒） |
| `stop_loss` / `take_profit` | `0.05` / `0.10` | 止损 / 止盈比例（相对成本价） |
| `intraday_auction` | `false` | 竞价扫描总开关（默认关，一次竞价请求都不发） |
| `auction_scan_at` | `["09:20", "09:25"]` | 扫描时刻，`HH:MM` 列表 |
| `auction_min_pct` / `auction_max_pct` | `2.0` / `9.0` | 竞价涨幅下限 / 上限（%），≥ 上限的是一字板、买不进 |
| `auction_boards` | 主板 / 创业板 / 科创板 / 北交所 | 参与扫描的板块；一个都不勾等于不限制 |
| `auction_min_amount` | `5e6` | 竞价成交额下限（元），不到就不参与 |
| `auction_min_volume_ratio` / `auction_min_score` / `auction_alert_max_items` | `2.0` / `2` / `10` | 打分门槛 / 命中门限（1~6）/ 一次最多推几条（≤50） |
| `intraday_anomaly` / `anomaly_alert_tags` | `false` / `[]` | 当日异动提醒（默认关）；只关心这些标签（空 = 全部） |
| `intraday_t` | `false` | 做T近似提示总开关（默认关） |
| `t_high_min_gain_pct` / `t_high_pullback_pct` / `t_low_min_drop_pct` / `t_low_rebound_pct` | `2.0` / `1.5` / `2.0` / `1.0` | 做T的四个阈值 |

**定时、概览与界面**

| 键 | 默认 | 说明 |
|---|---|---|
| `auto_run` | `false` | 每天自动运行（默认关，出厂状态不会自己跑） |
| `run_at` / `run_at_fallback` | `"16:00"` / `"19:15"` | 主跑时间；主跑没成功时到这个点补跑 |
| `market_overview` / `market_breadth` | `true` / `true` | 概览总开关；涨跌家数（多 6 个分页请求） |
| `market_indices` / `market_sentiment_indices` / `market_sector_indices` | 见上文 | 三组指数代码，写 `000001.SH=我的上证` 可自定义显示名 |
| `market_overview_ttl` | `55` | 概览缓存秒数（正整数） |
| `pool_view` / `ui_theme` | `"cards"` / `"silver"` | 池子默认视图（卡片 / 表格）；主题（银色 / 系统默认） |

## 五、关键行为（当前口径）

### 匹配口径：按时间自动切，没有开关

- **开盘时间**（交易日的 9:30–11:30 / 13:00–15:00）里跑的匹配是**实时口径**：用实时快照拼出"今天"这根 K 线，
  于是策略里的 `C`、`C/REF(C,1)-1`、`量比()`、`C>MA(C,5)` 一个字不用改就自动是盘中值。
- **非开盘时间**（收盘后 / 周末 / 节假日）用库里的日 K 线。
- 走实时还要同时满足：今天是交易日、库里还没有今天这根、**取得到实时快照**。任何一条不成立就退回日 K，
  并在结果里说清是哪一条。
- **没有**"盘中用实时数据"的开关，也不许加：这是内置规则。
- 界面上**三处**显示同一句「本次口径」：策略页【运行】结果、结果区结论、主窗口匹配完成结论。

### 来源列只写策略名

- 「来源」列回答"是哪条策略选出来的"，写的就是策略名本身，**不带任何前缀**。
- 用户手工加进去、没有策略来源的票才写「自选」。
- 库里存的内部合成名，以及老版本留下的前缀与组合尾巴，都**只在显示时剥掉**（`formulas` 的展示口径收在 `wording.py` 一处）；**一个字节的数据都不改**。

### 池子表头计数互斥

- `共 N 只（策略 M · 自选 K）`：**策略行 + 纯自选行 = 总数**，两个分项加起来不会大于总数。
- 同一只票既是策略选中又是自选时只占一行，来源写策略名；它在不在自选里看自选表与「监控开关」那一列。

### 随包策略 8 条

`formulas/` 里随包分发 8 条，与你自己写的策略**待遇完全相同**（勾上才跑、可改可删）：

`开盘抓涨停策略（超短）`、`尾盘匹配策略`、`首板缩量整理`、`短期反转`、`放量上攻`、`地量后放量变盘`、`均线多头排列`、`二板炸板（反指）`。

播种规矩（见 `formulas.py`）：

- **缺哪条补哪条** —— 新版本多带的策略会补进你的目录，不用去别处找文本；
- **同名不覆盖** —— 你已有的、改过的文件永远是你的；
- **删掉的不再补** —— 播过种的记录在 `.caishen-seeded.json` 里，你删除过的策略不会每次启动都长回来；
- **退役的不复制** —— 已下架的随包策略只在"与你没改过的老版本逐字节一致"时清理；改过的留着。

> 补齐与退役只在"随包目录 ≠ 用户目录"时才有意义（PyInstaller 版是这种形态）。
> **Nuitka 版**把随包策略直接放在 exe 同级的 `formulas/`，随包目录**就是**用户目录，本来就不用复制。

### 公式里能用的盘中快照字段

- 收盘型：`流通市值`（亿元）、`换手率`（%）。
- **盘中型四个**：`现价`（元）、`现涨幅`（**百分数**，3.2 表示 +3.2%）、`现量比`（倍）、`现换手`（%）。
- 四个盘中型字段只有"当下"这一个值：**非交易时段取不到**，用到它们的条件一律不成立（可能一只都不出），而且**没有历史、不能回测**。
- 取了快照时只取**一趟**，K 线与扩展字段共用同一份，避免同一轮里看到两个时刻的盘面。

### 通达信公式兼容

三档口径：**支持的**（粘进来就能用）、**忽略的**（画图语句、`COLORRED` 这类样式修饰，不影响匹配但会提示）、
**不支持的**（`WINNER` / `COST` / 跨周期 `C#WEEK` / 引用别的公式，给中文原因 + 替代写法）。

支持 75 个函数（引擎白名单里那些），`FINANCE` / `DYNAINFO` / `INBLOCK` 按本项目口径实现（分别等同流通市值 / 量比 / 热门行业），
【校验】里会各给一条提醒。**完整清单见 `docs/兼容性.md`**。

### 授权与试用

- 免费试用 **7 天**，到期后**策略编辑锁住**，点它会弹授权窗口（程序其余部分照常可用）。
- 机器码 `XXXX-XXXX-XXXX-XXXX`，注册码同形；注册码由机器码算出来，填进授权窗口点【注册】即可。
- **机器码只在打开授权窗口 / 点注册时才读**：读机器码在 Windows 上要起一个 PowerShell 问硬件，启动路径不读它。
- 试用期起点同时写 `%APPDATA%\CaishenHelper\license.json` 与数据库 `app_state` 表，取**较早**的那个；
  系统时间被回拨按**已到期**处理。

## 六、开发约定

### 测试

- **必须离屏跑**：`QT_QPA_PLATFORM=offscreen ... -m pytest -q`。界面用例在没有显示器的环境里建窗口。
- **不许放宽断言**：用例红了先查代码；把断言改松、加 skip、删用例都不是修法。
- 用例覆盖的是**当前口径**（口径类的用例会钉住"关不掉"、"互斥"、"前缀已剥掉"这些事实），改行为要连用例一起改。

### 注释与文案

- **中文注释写"为什么"**，不写"是什么"：为什么这么定、不这么定会出什么事、踩过哪个坑。
- 给人看的字符串一律中文短句。界面上的结论句是**纯文本**（进 QLabel），不要写 `**加粗**` 这类 markdown 记号。
- 口径文案**只有一份来源**：同一个数、同一件事在两处显示，必须走同一个函数。

### 版本号规则

- **小改动 +0.01**：末位加一（`1.3.0` → `1.3.1`）。
- **大升级 +0.1**：中段加一（`1.3.0` → `1.4.0`）。
- 两处必须同步，否则会出现"界面说这个版本、包是那个版本"：

| 位置 | 内容 |
|---|---|
| `src/laoa_trader/__init__.py` | `__version__`（唯一真源，界面 / 通知 / `--version` 都读它） |
| `pyproject.toml` | `[project] version` |

`build/nuitka_build.py` 的 `--product-version=` **打包时现读 `__version__`**（2026-09-28 起），不再是手抄的第三份字面量。

### 提交信息与文档同步

- 提交信息用**中文**，一句话说清这次改了什么。
- 改完顺手同步这些地方，别让两处说两套话：

| 改了什么 | 同步哪里 |
|---|---|
| 界面布局 / 页签 / 列 | `docs/开发文档.md`、本文件「功能一览」 |
| 配置键的增删改名 | `config.example.toml`、本文件「关键键」 |
| 版本号 | 上表三处 |
| 对外说法（定位、特色、截图） | `docs/软件介绍.md`、`网站/`（两边一起改） |
| 界面截图 | 重新生成 `docs/截图/`，再拷到 `网站/截图/` |
